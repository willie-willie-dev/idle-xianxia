# 页面与面板（实现）

对照：`design-docs/04-界面/04-01-页面导航框架.md`、`04-03-多角色账号系统.md`

## 两屏结构

| 屏 | 内容 |
|---|---|
| 角色列表 | 新建角色（输入道号）、角色卡片（境界·阶位 / 修为 / 第几天）、进入 / 删除 |
| 游戏页 | 角色信息、功法槽、背包、修为进度、灵根、灵地选择、动作按钮、修行日志、事件面板 |

切换：列表 → 游戏（进入 / 新建）；游戏 → 列表（返回，保留存档）。

## 游戏页元素

| 区域 | 展示内容 |
|---|---|
| 头部 | 角色名、境界·阶位、第 N 天、返回列表、删除角色 |
| 数值 | 修为 / 本境上限、突破所需、五行主属 |
| 功法 | 3 个槽位按钮（空槽显示「空」，点击切换生效）+ 每槽一个下拉（只列背包里已有的功法） |
| 背包 | 功法条目（名称 + 效率 + 装备到①②③） |
| 进度 | 修为进度条（封顶 100%） |
| 灵根 | 七通道百分比，主属高亮 |
| 动作 | 灵地下拉（火山 / 灵泉）、吸收灵气、突破、历练 |
| 日志 | 最近操作（吸收、突破、事件、装备、获得功法） |
| 事件面板 | 标题、正文、选项；选完后换成「你的选择 + 结果交代 + 徽标 + 继续」 |

## 交互规则

- 没有功法 / 未装备时，吸收给出提示、修为 +0、不耗天
- 修为不足时突破按钮禁用
- 事件一次只显示一条；选完必须点「继续」才收起
- 刷新页面自动回到上次的角色（记住当前角色）

## 与设计的差异

- 设计是「页面导航框架 + 切换动画 + 多角色账号」的完整结构；实现只有两屏、无动画
- 设计的多角色账号体系（登录 / 切换）未实现，只有本地的多角色列表
- 详见 `../差异对照表.md` 行 G1–G2
