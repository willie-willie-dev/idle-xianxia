## 已确认的口径（今天由 W 拍板，应回写设计）

1. **初始没有功法**，必须从历练事件获得，无功法不能涨修为
2. 事件选项要有**结果交代**，不同选项结果不同
3. 时间以**天**为最小单位，不同动作/事件耗时不同
4. 境界内部细分**前 / 中 / 后**
5. 功法可配置**多个槽位**，并有不同效率的功法用于测试
6. 增加**体力**（吸收消耗、打坐恢复、事件可扣）与**消耗品**（回体力 / 加修为 / 突破必成）
