> 这套文档是**实现侧的提炼**，不是设计稿、不贴源码、不写伪代码。
> 目的是：拿它和 `design-docs/` 对照时，一眼看出**做成了什么、和设计差在哪**。
>
> - 设计文档（权威）：`../design-docs/`
> - 可运行代码：`../mvp/`
> - 差异总表：`./差异对照表.md`

## 怎么用

1. 先看 `差异对照表.md` 的「待决」列，确认口径；
2. 再按章节回看实现细节；
3. 每个章节末尾都有「与设计的差异」小节，指向对照表对应行。
