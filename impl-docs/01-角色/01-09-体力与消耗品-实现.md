# 体力与消耗品（实现）

> 设计文档里没有独立章节（最接近 01-07 精神状态 / 01-05 修炼），本篇记录新增的实现侧规则。

## 体力

| 项 | 规则 |
|---|---|
| 上限 / 初始 | 100 / 100 |
| 吸收消耗 | 每次 5 点；不足 5 点时不能吸收（提示「体力不足，先打坐」） |
| 打坐 | 恢复 40 点，耗时 1 天；体力已满时提示「体力已满」 |
| 事件消耗 | 选项可带 `staminaCost`（10 / 15 / 20 / 25），结算时扣除，最低到 0 |
| 下限 / 上限 | 夹在 [0, 100] |

## 消耗品（实现 4 种）

| id | 名称 | 效果 | 数值 |
|---|---|---|---|
| `huiqi-dan` | 回气丹 | 恢复体力 | +30 |
| `zhixue-cao` | 止血草 | 恢复体力 | +15 |
| `juyuan-dan` | 聚元丹 | 增加修为（不超本境上限） | +40 |
| `pojing-dan` | 破境丹 | **突破加成**：有丹时突破必定成功并消耗 1 枚；无丹按 80% 成功率 | 每次 1 枚 |

- 背包里消耗品按 `itemId` **堆叠**（同一物品合并为一条，显示 ×N）
- 使用后数量 -1，扣到 0 自动移除
- 破境丹**不能手动使用**（背包里显示「突破消耗」，没有「使用」按钮）
- 有丹：突破时自动消耗 1 枚，本次**必定成功**
- 无丹：按基础成功率 **80%** 掷骰，失败扣 20% 修为（不扣丹）
- 界面提示：有丹「持有破境丹：本次突破必定成功」；无丹「无破境丹：本次突破成功率 80%」
