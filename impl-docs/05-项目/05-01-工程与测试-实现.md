# 工程与测试（实现）

对照：`design-docs/05-项目/05-01-研发总纲.md`

## 工程结构（实现侧）

| 位置 | 作用 |
|---|---|
| `mvp/` | 可运行的最小实现（纯前端 + 本地存档） |
| `mvp/src/types.ts` | 数据类型 |
| `mvp/src/data/` | 数值（境界表 / 功法库 / 地点 / 事件数据） |
| `mvp/src/systems/` | 纯函数：吸收、突破、修炼、背包 |
| `mvp/src/event/` | 事件系统独立模块（池 / 抽取 / 结算） |
| `mvp/src/time/` | 时间系统独立模块（推进 / 钩子） |
| `mvp/src/storage/` | 存档：接口 + IndexedDB / 内存两实现 |
| `mvp/src/app.ts` | 应用层：读档 → 算 → 写档 |
| `mvp/src/ui/` | 只负责渲染与绑定 |
| `mvp/tests/` | 11 个测试文件，98 个用例 |

## 分层约定

- `systems/`、`event/`、`time/` 是纯函数，不碰 DOM、不碰存储
- 所有可调数值集中在 `data/balance.ts` 与 `data/events.ts`
- `app.ts` 一次操作 = 读档 → 计算 → 写档 → 返回结果
- UI 不写规则

## 运行方式

| 目的 | 命令 |
|---|---|
| 跑测试 | `node --test tests/*.test.ts` |
| 本地预览 | `npx vite --port 5204`（或 `scripts/mvp-dev.sh`） |
| 构建 | `npx vite build` |

## 测试分布（98 个）

| 文件 | 覆盖 |
|---|---|
| 吸收 / 门禁 | 七通道公式、无功法 +0 |
| 突破 / 阶段 | 9 阶阈值、逐阶推进、失败扣 20% |
| 事件 / 事件系统 | 分池、不重复、种子、掉落、结果交代 |
| 背包 / 功法 | 获得去重、装备、切换 |
| 仓库 / 迁移 | 增删查改、老存档字段补齐、读不改写 |
| 时间 | 0/1/多天推进、钩子顺序与隔离 |

## 与设计的差异

- 设计总纲里的战斗、装备、性格等系统未进入实现，测试也未覆盖
- 设计的多端/账号/网络结构未实现；实现是单机本地
