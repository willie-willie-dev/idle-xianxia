# 实现总览（2026-11-17）

## 一句话

从零搭出一个**可玩的最小循环**：建角色 → 历练拿到第一本功法 → 装备 → 吸收灵气 → 攒修为 → 突破小境界；进度存浏览器本地，刷新不丢。

## 可运行状态

- 入口：本地 dev 服务（vite），页面两屏（角色列表 / 游戏页）
- 存档：浏览器 IndexedDB，库名 `dengxian-mvp`
- 测试：**106** 个纯函数/仓库/事件/体力测试，全绿
- 构建：`vite build` 通过

## 一次完整的玩法循环（实测数值）

1. 新建角色：炼气·前期，三槽全空，背包空
2. 无功法点吸收：修为 +0、不耗天（明确提示）
3. 历练：抽到「山道拾遗」，任一选项都保底给青木诀（进背包）
4. 装备青木诀到①：吸收一次修为 +10.6、耗 1 天
5. 攒到 100 → 突破：炼气·中期，修为扣 100

## 与设计的差异（摘要）

- 设计 **5 大境界**，实现 **3 个**（炼气/筑基/金丹）
- 设计修为阈值 **1000 / 5000** 量级，实现 **100 / 240 / … / 3200**（为 10 分钟内可体验）
- 设计 **5 栏功法 + 周天/灵气池**，实现 **3 槽 + 吸收即转修为**
- 设计事件有 **权重、刷新、消耗**，实现 **等概率、不重复、零消耗**
- 详细逐条见 `../差异对照表.md`
