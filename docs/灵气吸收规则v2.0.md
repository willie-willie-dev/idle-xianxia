## 一、核心逻辑

每次奇遇提供 **1~2种** 五行灵气。

所有灵气按**灵根比例总和 = 100%** 直接分配：
- 五行灵根（金木水火土）：只能吸对应属性，吸不到就拿 **0**
- 乾灵根：可吸收**所有五行灵气**，按乾比例分配
- 坤灵根：可吸收**所有五行灵气**，按坤比例分配，再 **×10%权重**

**关键点：不是"剩余量"模型，是按比例直接分配。**

---

## 二、计算公式

设总灵气量 = `rawTotal`

```
五行灵气吸收（仅匹配属性）：
  火灵根吸收量 = rawTotal × 火灵根比例（仅当灵气类型=火时，否则=0）
  水灵根吸收量 = rawTotal × 水灵根比例（仅当灵气类型=水时，否则=0）
  木灵根吸收量 = rawTotal × 木灵根比例（仅当灵气类型=木时，否则=0）
  金灵根吸收量 = rawTotal × 金灵根比例（仅当灵气类型=金时，否则=0）
  土灵根吸收量 = rawTotal × 土灵根比例（仅当灵气类型=土时，否则=0）

乾灵根吸收量 = rawTotal × 乾灵根比例 × 1.5（增幅50%）
坤灵根吸收量 = rawTotal × 坤灵根比例 × 0.1（权重10%）
```

## 三、举例验证

### 场景：乾50%、火30%、坤20%

| 灵气类型 | 火灵根(30%) | 乾灵根(50%) | 坤灵根(20%) |
|---------|------------|------------|------------|
| 100火灵气 | **30** | **50** | **2**（×0.1） |
| 100水灵气 | **0**（无法吸收） | **50** | **2**（×0.1） |

### 场景：乾70%、火15%、水10%、坤5%

| 灵气类型 | 火(15%) | 水(10%) | 乾(70%) | 坤(5%) |
|---------|--------|--------|--------|--------|
| 100火灵气 | **15** | 0 | **70** | **0.5**（×0.1） |
| 100水灵气 | 0 | **10** | **70** | **0.5**（×0.1） |
| 100土灵气 | 0 | 0 | **70** | **0.5**（×0.1） |

## 五、TypeScript 类型设计

```typescript
interface SpiritAbsorbResult {
  /** 各五行灵气原始量（提供多少） */

  /** 吸收后各灵气当前值 */
  afterSpiritQi: Record<SpiritType, number>;

  afterKun: number;
}
```
