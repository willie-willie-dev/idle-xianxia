# 核心玩法框架

> 版本：v0.1
> 状态：顶层设计
> 关联项目：登仙 Idle Xianxia
> 作用：所有子系统均衍生自本核心玩法，是游戏结构的最顶层

---

## 一、核心循环

游戏的核心循环是：**从角色界面触发，进入连续事件选择，获得回馈。**

```
角色界面（触发）
    │
    ▼
进入事件选择
    │
    ▼
事件选项
    │
    ▼
结算结果 + 获得回馈
    │
    ▼
角色成长（属性/性格/资源等）
    │
    ▼
回到角色界面
```

这是一条**闭合的反馈循环**，玩家的成长驱动来自这条循环，游戏中所有系统都服务于这条循环。

---

## 二、子系统衍生关系

基于核心循环，向外衍生三个子系统：

```
                    ┌──────────────────────────┐
                    │      核心玩法循环        │
                    │  角色界面 → 事件 → 回馈  │
                    └──────────┬───────────────┘
                               │
          ┌────────────────────┼────────────────────┐
          ▼                    ▼                    ▼
  ┌───────────────┐   ┌───────────────┐   ┌───────────────┐
  │  事件响应能力  │   │   战斗系统    │   │   回馈收益系统  │
  │               │   │               │   │               │
  │ · 事件生成器  │   │ · 战斗事件    │   │ · 角色回馈    │
  │ · 场景约束    │   │ · 战斗结算    │   │ · 战斗回馈    │
  │ · 五行性格    │   │ · 战斗奖励    │   │ · 事件回馈    │
  └───────────────┘   └───────────────┘   └───────────────┘
```

### 事件响应能力

由 `09-encounter-generator-framework.md` 实现。生成器根据角色当前状态生成事件，并处理性格偏移。

### 战斗系统

由 `04-event-system-expanded.md` 等文档实现。战斗是事件的一种类型，提供对抗性反馈循环。

### 回馈收益系统

收益的分类来源：
- **角色回馈**：境界突破、修炼等角色系统行为带来的属性增长
- **战斗回馈**：战斗结算后的战利品、灵气等
- **事件回馈**：事件选项结算后的奖励（灵气/属性/物品/经验/金币）

## 三、三条回馈循环

游戏内有三条并行的成长回馈循环，均服务于角色成长：

### 循环 A：角色成长循环（核心）

```
修炼/吐纳/境界提升
    │
    ▼
角色属性成长（境界、灵气储量）
    │
    ▼
解锁更强的事件和战斗
    │
    ▼
获得更好的回馈
    │
    ▼
继续成长
```

### 循环 B：战斗成长循环

```
进入战斗事件
    │
    ▼
战斗选项选择
    │
    ▼
结算（胜负 + 奖励）
    │
    ▼
战利品/灵气/属性
    │
    ▼
角色变强
    │
    ▼
接受更强挑战
```

### 循环 C：事件成长循环

```
进入事件（奇遇/人际/机缘等）
    │
    ▼
选项决策（受五行性格影响）
    │
    ▼
结算 + 五行性格偏移
    │
    ▼
角色属性 + 性格双重成长
    │
    ▼
新的事件倾向形成
```

## 四、核心界面入口

游戏的主入口是**角色界面**。

玩家从角色界面出发，选择历练方向（吸纳/奇遇/战斗/危机），进入相应的事件循环，获得回馈后回到角色界面，查看成长结果。

```
角色界面
    │
    ├── 吸纳灵气 ──→ 事件循环 ──→ 回馈
    │
    ├── 奇遇探宝 ──→ 事件循环 ──→ 回馈
    │
    ├── 争斗切磋 ──→ 战斗循环 ──→ 回馈
    │
    └── 危机四伏 ──→ 危机循环 ──→ 回馈
```
