## 一、系统架构

游戏核心系统划分为 **4 个顶层系统**：

```
角色系统（角色属性 / 装备 / 修炼）
├── 角色属性子系统
├── 装备子系统
└── 修炼子系统（功法 + 周天）
事件系统（事件 / 奇遇 / 事件维度 / 时间）
├── 事件子系统
│   ├── 事件维度框架（战斗/人际/奇遇分类）
│   ├── 五行性格映射
│   └── 关系维度体系
├── 奇遇子系统
└── 时间子系统
战斗系统
技能系统
```

---

## 二、系统职责

### 2.1 角色系统

| 子系统 | 职责 |
|--------|------|
| **角色属性** | 六维基础属性、境界体系、五行成长、升级与突破 |
| **装备** | 装备槽位、品质、强化、套装效果 |
| **修炼** | 五功法槽位、周天运转中枢、功法固定开销、道种提炼 |

### 2.2 事件系统

| 子系统 | 职责 |
|--------|------|
| **事件子系统** | 事件触发与结算、事件维度分类（战斗/人际/奇遇）、五行性格映射、关系维度体系 |
| **奇遇子系统** | 机缘类事件模板、灵气奖励 |
| **时间子系统** | 游戏内时间（纪元）、事件时间消耗、时间推进规则 |

### 2.3 战斗系统

- 伤害公式
- 回合制战斗流程
- 掉落机制

### 2.4 技能系统

- 主动/被动/天赋三类技能
- 境界解锁
- 战斗效果结算
