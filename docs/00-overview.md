## 一、系统架构

游戏核心系统划分为 **3 个顶层系统**：

```
角色系统（角色属性 / 装备 / 修炼 / 技能）
├── 角色属性子系统
├── 装备子系统
├── 修炼子系统（功法 + 周天）
└── 技能子系统
事件系统（事件 / 奇遇 / 事件维度 / 时间）
├── 事件子系统
│   ├── 事件维度框架（战斗/人际/奇遇分类）
│   ├── 五行性格映射
│   └── 关系维度体系
├── 奇遇子系统
└── 时间子系统
战斗系统
```

## 二、核心玩法框架

> 本章内容源自 `00-core-gameplay.md`，为游戏结构的最顶层设计。

### 2.1 核心循环

游戏的核心循环是：**从角色界面触发，进入连续事件选择，获得回馈。**

```
角色界面（触发）
    │
    ▼
进入事件选择
    │
    ▼
事件选项
    │
    ▼
结算结果 + 获得回馈
    │
    ▼
角色成长（属性/性格/资源等）
    │
    ▼
回到角色界面
```

这是一条**闭合的反馈循环**，玩家的成长驱动来自这条循环，游戏中所有系统都服务于这条循环。

### 2.2 子系统衍生关系

基于核心循环，向外衍生三个子系统：

```
                    ┌──────────────────────────┐
                    │      核心玩法循环        │
                    │  角色界面 → 事件 → 回馈  │
                    └──────────┬───────────────┘
                               │
          ┌────────────────────┼────────────────────┐
          ▼                    ▼                    ▼
  ┌───────────────┐   ┌───────────────┐   ┌───────────────┐
  │  事件响应能力  │   │   战斗系统    │   │   回馈收益系统  │
  │               │   │               │   │               │
  │ · 事件生成器  │   │ · 战斗事件    │   │ · 角色回馈    │
  │ · 场景约束    │   │ · 战斗结算    │   │ · 战斗回馈    │
  │ · 五行性格    │   │ · 战斗奖励    │   │ · 事件回馈    │
  └───────────────┘   └───────────────┘   └───────────────┘
```

### 2.3 三条回馈循环

游戏内有三条并行的成长回馈循环，均服务于角色成长：

**循环 A：角色成长循环（核心）**
```
修炼/吐纳/境界提升 → 角色属性成长 → 解锁更强事件和战斗 → 获得更好回馈 → 继续成长
```

**循环 B：战斗成长循环**
```
进入战斗事件 → 战斗选项选择 → 结算（胜负+奖励）→ 战利品/灵气/属性 → 角色变强 → 接受更强挑战
```

**循环 C：事件成长循环**
```
进入事件 → 选项决策（受五行性格影响）→ 结算 + 五行性格偏移 → 角色属性+性格双重成长 → 新的事件倾向形成
```

### 2.4 核心界面入口

游戏的主入口是**角色界面**。

玩家从角色界面出发，选择历练方向（吸纳/奇遇/战斗/危机），进入相应的事件循环，获得回馈后回到角色界面，查看成长结果。

```
角色界面
    │
    ├── 吸纳灵气 ──→ 事件循环 ──→ 回馈
    │
    ├── 奇遇探宝 ──→ 事件循环 ──→ 回馈
    │
    ├── 争斗切磋 ──→ 战斗循环 ──→ 回馈
    │
    └── 危机四伏 ──→ 危机循环 ──→ 回馈
```

## 三、系统职责

### 3.1 角色系统

| 子系统 | 职责 |
|--------|------|
| **角色属性** | 六维基础属性、境界体系、五行成长、升级与突破 |
| **装备** | 装备槽位、品质、强化、套装效果 |
| **修炼** | 五功法槽位、周天运转中枢、功法固定开销、道种提炼 |
| **技能** | 主动/被动/天赋三类技能、境界解锁、战斗效果结算 |

### 3.2 事件系统

| 子系统 | 职责 |
|--------|------|
| **事件子系统** | 事件触发与结算、事件维度分类（战斗/人际/奇遇）、五行性格映射、关系维度体系 |
| **奇遇子系统** | 机缘类事件模板、灵气奖励 |
| **时间子系统** | 游戏内时间（纪元）、事件时间消耗、时间推进规则 |

### 3.3 战斗系统

- 伤害公式
- 回合制战斗流程
- 掉落机制
