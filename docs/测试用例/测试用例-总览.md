# 登仙 · 手工测试用例（TC-001 起）

> **目的：** 将核心用户流程固化为可回归的测试用例，确保每次功能迭代后能快速验证功能完整性。
>
> **目录规则：** 所有用例归档于 `docs/测试用例/` 目录，按模块分文件。
> **编号规则：** `TC-{模块缩写}-{序号}`，如 `TC-CR-001` = Create Role 模块第 1 条。

## TC-CR-001 · 创建角色 → 踏入仙途

**模块：** 创建角色（Create Role）  
**设计文档：** `角色模板设计规范.md` §二（七灵根）、`多角色账号系统.md`  
**严重性：** P0（核心路径）

### 入口条件

- 应用已启动，访问 `http://127.0.0.1:30200/`
- 选角页（EntryScreen）已渲染，存在「+ 创建角色」按钮
- 已有角色数量 < 3（否则创建按钮隐藏）

### 前置数据

- localStorage 空（或仅有 ≤2 个角色存档）

---

### 测试步骤

| Step | 操作 | 验证点 |
|------|------|--------|
| 1 | 页面加载完成，截图存档 | 显示「仙途漫漫角色选择」标题 + 角色卡片列表（如有）+ 「+ 创建角色」按钮 |
| 2 | 点击「+ 创建角色」 | 页面跳转至 `CharacterCreate`，截图存档 |
| 3 | 检查初始状态 | 灵根总和显示 100%；默认乾=100%，其余=0%；性别默认未选中；「踏入仙途」按钮存在 |
| 4 | 填写角色名「测试角色」 | 输入框显示「测试角色」；长度合法（2-8字） |
| 5 | 点击「🎲 随机」一次 | 角色名被填充（2-8字中文）；截图存档灵根分配 |
| 6 | 点击「🔀 随机分配灵根」一次 | 乾/坤/火/水/木/金/土 数值变化；总和始终 = 100%；各灵根值为 5% 整数倍 |
| 7 | 切换性别为「♀ 女」 | 女 button 高亮/选中态 |
| 8 | 点击「踏入仙途」 | 页面跳转至 `GameScreen` 主界面，截图存档 |

---

### 预期结果

| 验证点 | 预期 | 实际 |

| 创角页初始灵根总和 | 100% | 待填写 |
| 随机灵根总和 | 100% | 待填写 |
| 踏入仙途后界面 | 显示角色名 + 境界「炼气」+ 道种进度 + 日期 | 待填写 |
| 英雄卡灵根标签 | 与创角时分配一致（如「乾灵根」或「火+乾」等） | 待填写 |
| 仙途札记 | 首行显示「欢迎踏入修仙之道……」 | 待填写 |
| localStorage | 写入新角色存档，数据结构包含 name/spritRoots/realm 等字段 | 待填写 |

## TC-CR-002 · 创角 → 灵根滑条坤自动计算

**模块：** 创建角色（Create Role）  
**设计文档：** `角色模板设计规范.md` §二、`01-角色属性系统.md` §灵根配比  
**严重性：** P0（核心数值逻辑）

### 入口条件

- 进入 `CharacterCreate` 页面（同 TC-CR-001 Step 2）

### 测试步骤

| Step | 操作 | 验证点 |
|------|------|--------|
| 1 | 页面加载完成，记录初始灵根总和 | 总和 = 100% |
| 2 | 点击「火」灵根按钮一次 | 火 = 5%；总和仍 = 100%（坤自动减少至 95%） |
| 3 | 连续点击「火」4次 | 火 = 25%；坤自动 = 75%；总和 = 100% |
| 4 | 连续点击「水」3次 | 水 = 15%；坤自动 = 60%；总和 = 100% |
| 5 | 检查总和标签 | 显示「总和：100%」 |
| 6 | 将乾调至 0%（连续点击20次） | 乾 = 0%；坤 = 60%（自动重新计算） |

---

### 预期结果

| 验证点 | 预期 |
|--------|------|
| 每调整一个非坤灵根，坤自动修正使总和=100% | ✅ |
| 各灵根值为 5% 整数倍 | ✅ |
| 任何时刻总和 = 100%（不允许超100或低于100） | ✅ |
