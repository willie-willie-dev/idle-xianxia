# 05-03-角色头像生成系统

> 版本：v0.1
> 状态：已并入仓库
> 说明：角色头像生成子系统。服务 `05-02` 角色模板：先定妆，再经 edit 派生八表情。工具在 `tools/avatar-gen/`。

本文件锁定头像套装怎么生成、角色卡写什么、八个表情各自允许什么。玩法数值不在这里。

---

## 1. 定位

本系统服务 [`05-02-角色模板设计规范`](./05-02-角色模板设计规范.md)。

`05-02` 规定一个角色的文字身份（境界、灵根、持有、遭遇）。本系统不改这些数值，只把「同一个人」收成可复用的头像套装：1 张定妆 + 8 张表情。界面、事件立绘、背景拼接都从这套图取，不各自重新文生图。

入口是 `tools/avatar-gen/gen-avatar-set.py`。随仓库的角色卡：

| 卡 | 路径 | 用途 |
|----|------|------|
| 傲娇红衣 | `tools/avatar-gen/cards/aojiao-hong.json` | 正红色调、华丽发饰、傲娇气质 |
| 剑修 | `tools/avatar-gen/cards/jianxiu.json` | 深青道袍、素银簪、不女性化 |

产物目录：`assets/avatars/<角色名>/`。密钥只从本机凭据库读，不进仓库。

## 2. 两阶段流程

一套图分两段。两段用的端点不同，不能合成一次调用。

### 2.1 定妆

`POST /v1/images/generations`。提示词由风格块、纯白背景、不可变身份、禁止项、可选色调与气质，以及「正常」表情拼成。默认风格 `cel`（国漫赛璐璐）；另有 `gongbi`、`pixel`。

这一张是身份底片。脸、头发、发饰的位置和数量、服饰、白底，都在这里定死。

### 2.2 edit 派生 8 表情

`POST /v1/images/edits`。把定妆图做成 data URI，放进 `image.url`。提示词只要求改表情，并重复两条锁：

- 保持身份、脸型比例、发型、发饰（位置与数量都不得改变）、服饰、纯白背景和画风，只改变表情。
- 不要改发饰位置与数量，不要加耳饰，不要换衣领，不要改脸型、画风、背景颜色。

默认八个表情全部派生。顺序与文件名前缀：正常、开心、大笑、冷淡、愤怒、厌恶、害羞、惊恐。

多张定妆候选用 `--seeds`（此时只出定妆）。挑中一张后用 `--master` 指向它再派生，避免每张表情换一张脸。

### 2.3 为什么不能逐张 txt2img

九张如果各自走 generations，就是九次独立采样。这个端点会忽略 `image`，参考图传了也不生效。脸型、发饰数量和左右、衣领、色调都会漂，套装不再是同一个人。

edit 以定妆像素为条件，提示词只放行表情。身份漂移时换定妆重跑 edit，不对单张表情重新文生图。

## 3. 角色卡字段

角色卡是 JSON。缺省卡在生成器内；`--card-file` 覆盖同名字段。`face` / `eyes` / `hair` / `ornament` / `robe` / `forbid` 也可用同名命令行参数再覆盖一层。

| 字段 | 写什么 | 进入提示词的方式 |
|------|--------|------------------|
| `face` | 脸型。轮廓、下巴、颧骨，写具体结构 | 【不可变身份】脸型 |
| `eyes` | 眼型、眼皮、眼尾、眉毛 | 【不可变身份】眼睛 |
| `hair` | 髻的数量与位置、刘海、鬓发长度 | 【不可变身份】发型 |
| `ornament` | 发饰种类、左右、数量、穗长 | 【不可变身份】发饰。必须写数量和左右，否则 edit 会改 |
| `earring` | 耳饰。没有就写「无」 | 【不可变身份】耳饰。缺省为「无」 |
| `robe` | 交领、右衽、颜色、纹样、有无披帛 | 【不可变身份】服饰 |
| `forbid` | 这张脸绝对不要的东西（别的髻、别的流苏、别的色） | 【禁止项】 |
| `theme` | 整套色调，如「正红、朱红、金线为主，禁止蓝绿紫」 | 只认 `--theme`。定妆写入【色调】；每张 edit 追加「保持色调」 |
| `persona` | 气质，如傲娇的下巴和视线 | 只认 `--persona`。只叠到 `--persona-on` 列出的表情，默认是正常、冷淡、害羞 |

`theme` 和 `persona` 可以写在卡里备忘。生成器不会从 JSON 自动读这两个字段，命令行没传就不进提示词。

## 4. 八个表情

每条 edit 都先加身份锁，再加下表这一条，再加「不要改发饰 / 耳饰 / 衣领 / 脸型 / 画风 / 背景」。

| 表情 | 定义 | 禁止 |
|------|------|------|
| 正常 | 视线平视镜头，眼睑自然睁开，眉毛平放，双唇自然闭合，嘴角平直 | （不单列。定妆用的就是这一条） |
| 开心 | 眼睛弯成月牙、下眼睑微鼓，颊上淡淡暖红，嘴角上扬约十五度，双唇轻闭 | （不单列。暖红只到「淡淡」） |
| 大笑 | 眼睛闭合成缝、眼角挤出细纹，双颊只是微微泛红，嘴张开露出上齿，头略后仰 | 不要腮红块、不要露龈过多、不要卡通夸张 |
| 冷淡 | 上眼睑半垂、眼神下移，面色偏白无血色，唇线平直、嘴角极轻微下压，下巴微抬 | 不要愤怒、不要冷笑 |
| 愤怒 | 眉心压低皱紧、眉梢上挑，眼睛睁大发亮，鼻翼微张，双唇紧抿，下颌前送 | 不要腮红感、不要青筋、不要扭曲脸型 |
| 厌恶 | 眼睛半眯、视线向下斜视，鼻梁明显皱起，上唇抬起、嘴角向一侧下拉，头略后仰偏开 | 不要吐舌、不要翻白眼、不要微笑 |
| 害羞 | 头低下约十度、下巴内收，视线避开镜头落在左下方，上眼睑遮住一半瞳孔，颧骨处极淡且左右对称的薄红，双唇抿成放松的线 | 不要微笑、不要露齿、不要直视镜头、不要扩散红晕 |
| 惊恐 | 眉毛高高扬起、眉心起竖纹，眼睛瞪大、瞳孔略缩小、露出一点眼白，肤色发白，嘴微张、唇瓣轻颤，肩膀缩起 | 不要瞳孔放大（那是震惊）、不要尖叫过大 |

气质词不要拿去改这八条的嘴型和视线。傲娇只叠在默认的正常、冷淡、害羞上。

## 5. 纯白背景

背景锁定为 `#FFFFFF` 单一平涂：无渐变、无投影、无纹理、无边框、无装饰。背景颜色不得随情绪或服饰改变。

原因是后面的抠图和背景拼接。纯白与头发、衣缘分离得开，rembg 的边缘不至于吃进一块带色的底。抠完的透明图才能贴到不同界面底上。底若跟着表情变色，同一套头像拼不齐，发丝边缘会留一圈原背景。

装了 Pillow 时，生成器检查四个角是否接近纯白（通道值 ≥ 250）。这只是验收，不代替提示词里的白底约束。

## 6. 后处理管线

生成请求不负责最终像素尺寸（接口不接受 `size`）。全尺寸图出来之后，按这个顺序做：

1. **rembg 抠图。** 生成器的 `--cutout` 走本机 rembg，把每张 JPEG 收成 `alpha/` 下的透明 PNG。先在全尺寸上抠，发丝还在。
2. **背景合成。** 透明图叠到界面或场景底上。白底已经去掉，同一张脸可以换底，不用为每块界面重画。
3. **降采样 256 / 128。** 合成之后收到两档，给定妆和八个表情各留一份，给界面头像用。先合成再缩小，避免先缩小把发丝吃进背景再抠不干净。

第 2、3 步是套装进界面前的管线，生成器脚本停在可选的第 1 步。

## 7. 已知失败模式与对策

| 失败 | 表现 | 对策 |
|------|------|------|
| 发饰漂移 | edit 改了簪、步摇的位置或根数，左右对调，多出一条穗 | 发饰数量和左右写进 `ornament`；`forbid` 写明不要的对称和流苏。edit 提示词锁「位置与数量都不得改变」。漂了就换定妆，用 `--master` 重跑 edit，不要对那一张重新 txt2img |
| 红晕不对称 | 开心、大笑、害羞一边红一边不红，或红块糊出颧骨 | 害羞写明左右对称的薄红，并禁止扩散红晕。大笑禁止腮红块。愤怒禁止腮红感。红块不合格就重跑该表情的 edit，不改身份段 |
| 色情化 | 胸像被画成暴露、性化姿势，或把气质画成挑逗 | 构图锁方形胸像。`robe` 写死交领与覆盖范围。`forbid` 禁止额外裸露。气质只叠到 `--persona-on`，性格词不改写成挑逗 |
| 幼态二次元化 | 成人角色滑成大眼、尖下巴、幼态美少女 | `face` / `eyes` 写具体结构（长方脸、单眼皮、剑眉这一类）。`forbid` 写不要的脸型。风格用国漫赛璐璐、工笔或像素，不用「二次元美少女」当提示。`--seeds` 先挑一张成人比例的定妆，再派生 |

## 8. 成本

默认模型 `grok-imagine-image-2.0`：$0.04/张。

一套 = 1 张定妆 + 8 张表情 = 9 张，约 $0.36。

1.0 模型的表情编辑是 $0.02/张。`--seeds N --only-master` 只付 N 张定妆。
