## 七、境界突破逻辑

### 大境界 vs 小境界区分

```
小境界（灵根不变，仅灵气提升）：
  炼气初期 → 炼气中期 → 炼气后期

大境界（需要物品，跨越境界）：
  炼气后期 → 筑基初期
  筑基后期 → 金丹初期
  金丹后期 → 元婴初期
  元婴后期 → 化神初期
```

### 小境界突破条件

```
突破条件：七种灵气全部存满
突破结果：境界升级（无需物品）
```

### 大境界突破条件

```
突破条件：
  1. 七种灵气全部存满
  2. 持有对应突破物品

突破结果：境界跨越，进入下一境界初期（需消耗物品）
```

---
