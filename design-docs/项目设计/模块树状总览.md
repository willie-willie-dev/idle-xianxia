## 系统接口矩阵

> 确认时间：2026-07-21
> 接口类型默认双向；单向接口在「方向」列标注。

| 系统对 | 接口类型 | 方向 |
|--------|---------|------|
| **Character ↔ Equipment** | 属性（`Stats`） | 双向 |
| **Character ↔ Skill** | 境界解锁条件 + 技能效果（属性/触发） | 双向 |
| **Character ↔ Battle** | 战力属性 + 战斗奖励 | 双向 |
| **Character ↔ Cultivation（周天）** | 灵气/境界进度 + 角色上下文（修炼效率/上限） | 双向 |
| **Character ↔ Event** | 事件交互（性格偏移 + 回报变更 + 角色上下文） | Event↔Character 双向 |
| **Cultivation（周天）↔ Event** | 灵气消耗/获得 | 双向 |
| **Event ↔ Time** | 时间消耗 | Event→Time（单向，省略反向） |
| **Event ↔ Battle** | 战斗触发 + 战斗结果 | 双向 |
| **Skill ↔ Event** | 技能解锁/触发 + 技能效果 | 双向 |

### 接口设计说明

1. **Character ↔ Event 归并原则**
   - 性格偏移（影响事件选项倾向）和 回报/变更（属性结算结果）属于不同语义，但共享「事件交互」这一统一接口大类
   - 方向通过事件流程隐式确定，不需要在矩阵中拆成多行

2. **Character ↔ Cultivation 合并原则**
   - 灵气和境界进度都是修炼资源，下游消费者一致，合并为「修炼资源/进度」接口

3. **Event → Time 单向省略**
   - 时间不主动影响事件生成，反向无意义，省略不标

4. **物品/装备接口**
   - 装备系统已有独立「属性」接口，物品的获得/消耗通过「属性变更」接口覆盖，不单独列出
