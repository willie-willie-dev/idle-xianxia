## 一、模块定位

简化版战斗系统定义角色的**战斗攻防两半**：

- **防御**：HP + 5 维响应值 + 9 伤害全抗性矩阵
- **进攻**：神通 + 修为 + 周天（灵气池 ↔ 修为 双向转化）

**设计原则**：

1. **防御只有 HP 一个生存值**（无 ATK/DEF）
2. **进攻靠 7 灵根灵气池 + 修为 + 神通**
3. **5 维响应值直接复用 10 号肉体五行**（抗性 + 神通五行加成）
4. **9 伤害全抗性矩阵**（每种伤害对 5 肉体五行有不同抗性系数，可负=易伤）
5. **神通是数据驱动的开放集合**（不限于 9 种，可扩展；每个神通自定义）
6. **周天双向运转**：灵气→修为（低损耗，常规）；修为→灵气（高损耗，应急）
7. **战意系统暂搁置**（13 号 9 开放点待重开；本系统独立运作）

### 3.2 5 维响应值（肉体五行 · 0-100）

> **复用 10 号 v1.0 锁定的肉体五行**（火·迅捷 / 水·灵巧 / 木·生机 / 金·坚韧 / 土·厚重）— 数值形式沿用 10 号 0-100 程度值。

| 五行 | 肉体词 | 10 号锁定含义 | 本系统作用 |
|------|-------|--------------|------------|
| 火 | 迅捷 | 爆发与移动速度 | 抗冲撞/灼烧/雷击 + 神通火系加成 |
| 水 | 灵巧 | 手法、身法、细作精度 | 抗缠绕/冰冻 + 神通水系加成 |
| 木 | 生机 | 生命活力与再起余地 | 抗腐蚀/缠绕 + 神通木系加成 |
| 金 | 坚韧 | 筋骨坚而能韧 | 抗斩劈/穿刺 + 神通金系加成 |
| 土 | 厚重 | 体量、抗击打、压得住 | 抗挤压 + 兜底抗性 + 神通土系加成 |

> **关键不破坏 10 号锁定**：本系统**直接复用**肉体五行的 5 词和 0-100 数值形式，10 号 v1.0 维持原状。

## 四、9 伤害类型 · 全抗性矩阵

> 数值是 v0.1 草案，待 W 精调。**可扩展**：神通可定义抗性矩阵外的伤害类型，需配抗性系数（见 §十 开放点）。

| 伤害 | 🔥 迅捷 | 💧 灵巧 | 🌳 生机 | ⚒️ 坚韧 | 🪨 厚重 | 逻辑 |
|------|--------|--------|--------|--------|--------|------|
| **斩劈** | 0 | 0 | 0 | **80%** | 20% | 锋利→主金，厚皮→土辅助 |
| **冲撞** | **60%** | 0 | 0 | 0 | 40% | 速度躲冲→主火，厚重辅助 |
| **挤压** | 0 | 0 | 20% | 20% | **60%** | 钝压→主土，坚韧/生机辅助 |
| **缠绕** | 0 | **60%** | **80%** | **-10%** | 40% | 灵巧脱缠+生机挣脱；金属反易伤 |
| **灼烧** | **60%** | 20% | **-20%** | 0 | 40% | 速度躲火→主火+土；生机反易伤 |
| **冰冻** | 0 | **40%** | **-20%** | 20% | 20% | 手法破冰→主水；生机反易伤 |
| **腐蚀** | 0 | 0 | **80%** | 0 | 20% | 再生抗毒→主木，厚重辅助 |
| **穿刺** | 0 | 0 | 0 | **80%** | 20% | 锋利→主金，厚皮→土辅助 |
| **雷击** | **40%** | 0 | 0 | **40%** | 20% | 速度躲雷+金导电→主火金，厚重辅助 |

**关键观察**：

- 🪨 **土·厚重 = 兜底抗性**：9 种伤害里 7 种都有 20-60% 土抗 → 符合"厚重=抗打"的 10 号锁定意象
- 🌳 **木·生机 = 双刃剑**：抗腐蚀 80% / 抗缠绕 80%（再生抗毒+挣脱），但**被灼烧/冰冻反易伤 -20%**（生机被热/寒克制）→ 策略深度
- ⚒️ **金·坚韧 = 抗锐 + 被缠**：抗斩劈/穿刺 80%，但**被缠绕反易伤 -10%**（金属易被缠锁）→ 跟"金·灵魂=刚毅，硬但易被绕后"呼应

## 五、抗性公式 + 伤害结算

```
抗性 R = Σ(角色肉体五行值 × 该伤害的抗性系数) / 100
R 钳制范围：[-30%, +80%]
最终伤害 = 基础伤害 × (1 - R)
```

- **减伤最多 80%**（R=80%）—— 留 20% 给装备/buff/战意加成
- **易伤最多 30%**（R=-30%）—— 不能一击致命，留 70% 兜底

### 示例

角色肉体：火 60 / 水 40 / 木 80 / 金 90 / 土 50

| 伤害 | R 计算 | R 值 | 实际伤害系数 |
|------|--------|------|-------------|
| **穿刺** | 0+0+0+72+10 = 82 | 钳 80% | **×0.20**（减伤 80%） |
| **缠绕** | 0+24+64-9+20 = 99 | 钳 80% | **×0.20**（减伤 80%） |
| **灼烧** | 36+8-16+0+20 = 48 | 48% | **×0.52**（减伤 48%） |
| **腐蚀** | 0+0+64+0+10 = 74 | 74% | **×0.26**（减伤 74%） |
| **雷击** | 24+0+0+36+10 = 70 | 70% | **×0.30**（减伤 70%） |

## 六、灵气系统

### 6.1 7 灵根池

7 灵根池各自独立，平日修炼按 7 灵根比例（02 号 + 灵气 v2.0 规则）分配灵气。

| 灵根 | 吸收规则 | 消耗要求 |
|------|---------|---------|
| 火 | 仅吸火灵气 | 仅供要求火的灵气消耗 |
| 水 | 仅吸水灵气 | 仅供要求水的灵气消耗 |
| 木 | 仅吸木灵气 | 仅供要求木的灵气消耗 |
| 金 | 仅吸金灵气 | 仅供要求金的灵气消耗 |
| 土 | 仅吸土灵气 | 仅供要求土的灵气消耗 |
| **乾** | **可吸所有 5 行灵气** | **空属性**：**只能应对"不要求灵根"的神通** |
| **坤** | **可吸所有 5 行灵气** | **万能属性**：**适配任何灵气要求** |

### 6.2 乾/坤特殊规则（已锁定）

- **乾 = 空属性**：乾灵气**不能**适配任何灵根要求；**只能**用于「qiRequirement 全缺省/0」的神通
- **坤 = 万能属性**：坤灵气可**替代**任何灵根要求（填充任何灵根的消耗）

**举例**：
- 神通要求 `fire: 100, kun: 20` → 100 火灵气 + 20 坤灵气 ✅
- 神通要求 `qian: 50`（只要求乾）→ 50 乾灵气（无灵根要求）✅
- 神通要求 `fire: 100, qian: 20` → ❌ **不允许**（乾不能适配灵根要求）
- 神通要求 `fire: 100, kun: 20`（坤替代 20 火）→ ✅ 允许（坤万能）

### 6.3 修为系统

**修为** = 专用于境界提升的长期资产。

- **与灵气池分离**：修为不进灵气池，灵气池不进修为（除非周天运转）
- **境界提升消耗修为**（具体规则见 02 号境界系统）
- **战斗可应急**：修为 → 灵气池（高损耗，见 §6.4）

### 6.4 周天运转

**周天 = 双向运转系统**（06 号紫薇位功法实现）

| 方向 | 触发 | 转化率 | 损耗率 | 用途 |
|------|------|--------|--------|------|
| **灵气 → 修为** | 平日修炼 / 战斗间隙（自动） | **95%** | 5% | 常规蓄积修为 |
| **修为 → 灵气** | 战斗应急（手动触发） | **30%** | **70%（损耗极大）** | 灵气耗尽时应急 |

> **数值是 v0.2 草案，待 W 精调。** 核心语义：修为是稀缺资产，应急挪用代价极高。

### 6.5 灵气-修为流转图

```
┌─────────────────────────────────────────────┐
│  平日修炼                                    │
│    1. 灵气吸收（按 7 灵根比例）              │
│    2. 蓄积到灵气池                          │
│    3. 周天运转 → 修为（95% 转化）           │
└─────────────────────────────────────────────┘
            ↓
┌─────────────────────────────────────────────┐
│  战斗                                       │
│    1. 灵气池消耗（释放神通）                 │
│    2. 灵气耗尽？→ 修为 → 灵气（30% 转化）  │
│    3. 境界提升消耗修为（独立路径）            │
└─────────────────────────────────────────────┘
```

## 七、神通系统（数据驱动开放集合）

### 7.1 核心理念

**神通不是一个统一类型，而是开放集合**。会有上百种不同神通，每个神通独立定义三件套：
1. **灵气要求**（多灵根组合）
2. **伤害类型**（自定义，可扩展）
3. **影响比例**（自定义）

> 这跟传统 RPG 的"技能树"或"法术分类"思路完全不同——每个神通是个**独立配置**。

### 7.2 数据结构

```typescript
interface ShenTong {
  /** 唯一 ID */
  id: string;
  
  /** 名称 */
  name: string;
  
  /** 描述 */
  description: string;
  
  /** 灵气要求（多灵根组合；缺省/0 = 不要求该灵根） */
  qiRequirement: {
    fire?: number;    // 火灵气
    water?: number;   // 水灵气
    wood?: number;    // 木灵气
    metal?: number;   // 金灵气
    earth?: number;   // 土灵气
    qian?: number;    // 乾灵气（空属性）
    kun?: number;     // 坤灵气（万能属性）
  };
  
  /** 伤害类型（开放集；可扩展） */
  damageType: string;  // '斩劈' | '冲撞' | '挤压' | '缠绕' | '灼烧' | '冰冻' | '腐蚀' | '穿刺' | '雷击' | ...其他
  
  /** 影响比例：每单位灵气造成的 HP 上限 % 伤害 */
  damageRatio: number;  // 如 0.10 = 10% HP 上限 / 单位灵气
  
  /** 五行加成（可选）：5 维响应值对输出的加成 */
  elementBonus?: {
    fire?: number;    // 火·迅捷加成（如 0.2 = +20%）
    water?: number;
    wood?: number;
    metal?: number;
    earth?: number;
  };
}
```

### 7.3 释放规则

1. **灵气检查**：当前灵气池（对应灵根） ≥ 神通灵气要求
2. **扣除灵气**：从灵气池扣除
3. **伤害计算**：
   ```
   伤害 = damageRatio × HP上限 × 灵气消耗量 × (1 + 五行加成) × (1 - 抗性R)
   ```
4. **HP 扣减**：被攻击方 HP -= 伤害

### 7.4 五行加成公式

```
五行加成 = Σ(对应 5 维响应值 × elementBonus 系数) / 100
加成范围：[-30%, +80%]（同抗性 R 的钳制）
```

> **示例**：火系剑诀 elementBonus = `{ fire: 0.2 }`，角色火·迅捷 = 60 → 加成 = 60 × 0.2 / 100 = **+12%**

### 7.5 神通示例

**示例 1：火系剑诀**
```typescript
{
  id: 'fire-sword-1',
  name: '火系剑诀',
  description: '以火灵气驱动剑招，附加灼热之意',
  qiRequirement: { fire: 100, kun: 20 },
  damageType: '斩劈',
  damageRatio: 0.10,  // 10% HP / 单位灵气
  elementBonus: { fire: 0.2 }  // 火·迅捷 +20%
}
```

**示例 2：冰封术**
```typescript
{
  id: 'ice-seal-1',
  name: '冰封术',
  description: '以水灵气凝聚寒意',
  qiRequirement: { water: 150 },
  damageType: '冰冻',
  damageRatio: 0.08,
  elementBonus: { water: 0.15 }
}
```

**示例 3：通用型护盾**（用乾灵气）
```typescript
{
  id: 'qian-shield-1',
  name: '乾灵护盾',
  description: '以乾灵气凝聚护盾（无灵根要求）',
  qiRequirement: { qian: 80 },  // 只要求乾
  damageType: '无',  // 纯防御，无伤害
  damageRatio: 0,    // 无伤害
  elementBonus: { earth: 0.1 }  // 仍可有五行加成
}
```

## 十二、战斗示例

### 场景

- **角色 A**（攻方）：肉体 火 60 / 水 40 / 木 80 / 金 90 / 土 50，HP 1000，灵气池 火 500 / 坤 30
- **角色 B**（守方）：肉体 火 60 / 水 40 / 木 80 / 金 90 / 土 50，HP 1000，灵气池全空
- **神通**：「火系剑诀」= `{ fire: 100, kun: 20, damageType: '斩劈', damageRatio: 0.10, elementBonus: { fire: 0.2 } }`

### 释放「火系剑诀」

1. **灵气检查**：A 火灵气 500 ≥ 100 ✅；A 坤灵气 30 ≥ 20 ✅
2. **扣除**：火灵气 500→400；坤灵气 30→10
3. **伤害计算**：
   - 抗性 R（B 对斩劈）= 0+0+0+72+10 = 82 → **钳 80%**
   - 五行加成（火·迅捷 60 × 0.2 / 100）= **+12%**
   - **伤害 = 0.10 × 1000 × 1 × 1.12 × (1-0.80) = 22.4 HP**
4. **HP 扣减**：B HP 1000 → 977.6
5. **回合结束**

### 继续

- A 继续释放火系剑诀（剩余火灵气 400，可再释放 4 次）
- 每次伤害约 22.4 HP（受抗性钳制到 80%）
- 释放 4 次后 A 火灵气耗尽；坤灵气也快耗尽
- A 可选择：
  - (a) 切换其他神通（如果还有）
  - (b) **触发修为→灵气应急**（70% 损耗，30% 转化）—— 代价大
