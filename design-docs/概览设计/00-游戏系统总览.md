## 一、系统架构

游戏核心系统划分为 **3 个顶层系统**：

```
角色系统（角色属性 / 装备 / 修炼 / 技能）
├── 角色属性子系统
├── 装备子系统
├── 修炼子系统（功法 + 周天）
└── 技能子系统
事件系统（事件 / 奇遇 / 事件维度 / 时间）
├── 事件子系统
│   ├── 事件维度框架（战斗/人际/奇遇分类）
│   ├── 五行性格映射
│   └── 关系维度体系
├── 奇遇子系统
└── 时间子系统
战斗系统
```

## 二、核心玩法框架

> 本章为游戏结构的最顶层设计索引。已于 **2026-08-04** 重新独立为 [`01-核心玩法.md`](./01-核心玩法.md)。

### 2.1 核心循环

**从角色界面触发，进入连续事件选择，获得回馈。** 闭合反馈循环，全系统服务于此。

→ 详见 [`01-核心玩法.md` §二](./01-核心玩法.md)

### 2.2 子系统衍生关系

核心循环向外衍生：事件响应能力、战斗系统、回馈收益系统。

→ 详见 [`01-核心玩法.md` §2.1](./01-核心玩法.md)

### 2.3 三条回馈循环

角色成长循环（核心）、战斗成长循环、事件成长循环，三者并行服务于角色成长。

→ 详见 [`01-核心玩法.md` §2.2](./01-核心玩法.md)

### 2.4 核心界面入口

主入口为角色界面；历练方向（吸纳 / 奇遇 / 战斗 / 危机）进入对应循环后回流。

→ 详见 [`01-核心玩法.md` §2.3](./01-核心玩法.md)

## 三、系统职责

### 3.1 角色系统

| 子系统 | 职责 |
|--------|------|
| **角色属性** | 六维基础属性、境界体系、五行成长、升级与突破 |
| **装备** | 装备槽位、品质、强化、套装效果 |
| **修炼** | 五功法槽位、周天运转中枢、功法固定开销、道种提炼 |
| **技能** | 主动/被动/天赋三类技能、境界解锁、战斗效果结算 |

### 3.2 事件系统

| 子系统 | 职责 |
|--------|------|
| **事件子系统** | 事件触发与结算、事件维度分类（战斗/人际/奇遇）、五行性格映射、关系维度体系 |
| **奇遇子系统** | 机缘类事件模板、灵气奖励 |
| **时间子系统** | 游戏内时间（纪元）、事件时间消耗、时间推进规则 |

### 3.3 战斗系统

- 伤害公式
- 回合制战斗流程
- 掉落机制
