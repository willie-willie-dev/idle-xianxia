## 一、模块定位

精神状态是**角色的临时心理状态**，决定"角色当前**心态如何**"——影响行为倾向、战斗效率、修炼效率、奇遇触发。

### 关键边界

| 系统 | 文档 | 性质 | 持续时间 |
|------|------|------|---------|
| 性格/灵魂/肉体 | 10 号 v1.0 | 基础属性（底色） | 长期（基本不变） |
| **精神状态** | **15 号（本系统）** | 临时状态（心态） | 几周到几月 |
| 战意 | 13 号 v0.2 | 战斗决策 | 每回合 |

> **精神状态 = "角色当前心情"**；性格/灵魂 = "角色底色"；战意 = "角色当前意愿"。

## 二、9 个精神状态 · 3×3 矩阵

```
                          烈度
              消极 (-)         中性 (0)         积极 (+)
         ┌─────────────────┬─────────────────┬─────────────────┐
   强    │    焦虑          │      警觉        │    振奋          │
  度     │  （长期担忧）   │   （持续警惕）  │   （持续积极）  │
  高    ├─────────────────┼─────────────────┼─────────────────┤
         │    自卑          │      迷茫        │    自信          │
  中    │ （退缩不前）    │   （方向不清）  │   （相信能赢）  │
         ├─────────────────┼─────────────────┼─────────────────┤
   强    │    消沉          │      平静        │    专注          │
  度     │ （全面低落）    │   （稳定发挥）  │   （持续专注）  │
  低    │                  │                  │                  │
         └─────────────────┴─────────────────┴─────────────────┘
```

> 矩阵轴名（"烈度"/"强度"）省略。3×3 矩阵体现二维：**烈度**（情绪正负）× **强度**（激活水平）。

### 9 个状态明细

| # | 状态 | 位置 | 含义 | 草案行为影响（**v0.1 暂不锁定**） |
|---|------|------|------|----------------------------------|
| 1 | **焦虑** | 强·消 | 长期担忧 | 战意切换 +30% / 失误率 +10% |
| 2 | **警觉** | 强·中 | 持续警惕 | 抗偷袭 +20% / 反应快 |
| 3 | **振奋** | 强·积 | 持续积极 | 主动触发 / 战斗坚持 |
| 4 | **自卑** | 中·消 | 退缩不前 | 突破成功率 -10% / 倾向保守 |
| 5 | **迷茫** | 中·中 | 方向不清 | 战意随机 / 决策犹豫 |
| 6 | **自信** | 中·积 | 相信能赢 | 突破成功率 +10% / 战意 A 攻击 |
| 7 | **消沉** | 弱·消 | 全面低落 | 所有效率 -20% |
| 8 | **平静** | 弱·中 | 稳定发挥 | 抗战意切换 +20% |
| 9 | **专注** | 弱·积 | 持续专注 | 修炼效率 +15% / 失误率 -20% |

> **行为影响全部标"草案待定"**——W 指示"暂时不用"，v0.1 不锁定具体数值。

## 三、三层架构 · 性格 / 精神状态 / 战意

```
┌──────────────────────────────────────────────────────────┐
│ 性格 / 灵魂 / 肉体（10 号 · v1.0 锁定）                   │
│  ▸ 基础属性 · 相对稳定（0-100 数值）                    │
│  ▸ 火·热血 / 火·果断 / 火·迅捷 等 25 词                │
└──────────────────────────────────────────────────────────┘
                          ↓ 影响
┌──────────────────────────────────────────────────────────┐
│ 精神状态（15 号 · 本系统）                              │
│  ▸ 临时状态 · 随事件变化（持续几周到几月）              │
│  ▸ 9 个状态（3×3 矩阵）                                │
└──────────────────────────────────────────────────────────┘
                          ↓ 影响
┌──────────────────────────────────────────────────────────┐
│ 战意（13 号 · v0.2 锁）                                 │
│  ▸ 战斗决策 · 每回合选                                  │
│  ▸ 11 类 A-K                                            │
└──────────────────────────────────────────────────────────┘
```

### 关键不重复原则

| 层级 | 性质 | 变化频率 | 跟其他层的关系 |
|------|------|---------|----------------|
| **性格/灵魂/肉体** | 基础属性 | 长期（基本不变） | 决定精神状态的"底色" |
| **精神状态** | 临时状态 | 几周到几月 | 受性格"加权"影响，独立变化 |
| **战意** | 战斗决策 | 每回合 | 受性格 + 精神状态双重影响 |

### 战意倾向综合公式（v0.1 草案 · 待公式化）

```
战意倾向 = 性格基础（10 号）+ 灵魂修正（10 号）+ 精神状态加成（15 号）+ 战意切换成本
```

**举例**：
- 角色 A：火·热血 80 + 火·果断 70（灵魂）+ 自信 70（精神状态）→ 战意 = 强烈倾向 A 攻击
- 角色 A 突破失败后：火·热血 80 + 火·果断 70 + 自信 20 / 消沉 50 → 战意倾向 I 投降（精神压制）
- 角色 B：土·隐忍 90 + 平静 80（精神状态）→ 战意 = 稳定 E 防御

## 四、数值化（0-100）+ 自然衰减

### 每个状态 = 0-100 程度值

| 范围 | 程度 | 行为影响 |
|------|------|---------|
| 0-20 | **淡漠** | 不影响行为 |
| 21-50 | **潜在** | 暗中影响决策倾向 |
| 51-80 | **明确** | 有意识地体现 |
| 81-100 | **狂热** | **驱动一切**（可能做出极端行为） |

### 自然衰减（v0.1 草案）

- 每个状态向 50（中位）回归 ±2/7 天
- 事件触发的状态变化在 7 天内不自然衰减

### 性格"加权"精神状态（v0.1 草案 · 待公式化）

- 性格强时（火·热血 90），精神状态影响被**放大**（如"自信 60"实际效果 +15%）
- 性格弱时（火·热血 20），精神状态影响被**压制**（如"自信 60"实际效果 -15%）
- **正式公式待 W 拍板**

## 五、触发器（事件 → 状态变化 · v0.1 草案）

| 事件 | 影响状态 |
|------|---------|
| 突破成功 | 自信 +10 / 振奋 +5 / 焦虑 -5 |
| 突破失败 | 自卑 +10 / 消沉 +5 / 焦虑 +5 / 自信 -10 |
| 战斗胜利 | 自信 +5 / 振奋 +3 |
| 战斗失败 | 消沉 +3 / 焦虑 +3 |
| 死亡/濒死 | 消沉 +10 / 焦虑 +5 |
| 际遇·奇遇 | 按事件影响相关状态 |
| 时间流逝 | 自然衰减 ±2/7 天 |

> 数值是草案，**v0.1 暂不锁定**。
