## 一、模块定位

执念系统是**角色驱动的状态机层**，决定"角色**想要什么**"——驱动行为决策、触发相关事件、影响修炼/战斗/社交/奇遇。

**关键边界**：

| 层 | 文档 | 职责 |
|---|------|------|
| 性格（价值取向） | 10 号 v1.0 | "更认哪种对"（事件价值拉力） |
| 灵魂（响应方式） | 10 号 v1.0 | "压力来时神识怎么接招"（人际/战斗） |
| 肉体（身法体质） | 10 号 v1.0 | "肉身扛得住什么"（战斗/身法） |
| **执念（驱动状态）** | **15 号（本系统）** | **"角色想要什么"（行为驱动力）** |

> **执念是状态机**（随事件变化），性格/灵魂/肉体是基础属性（相对稳定）。执念**驱动行为**，性格/灵魂/肉体**提供基础响应**。

## 三、角色执念配置

每个角色 = **1 主要执念 + 0-2 次要执念**：

| 类型 | 数量 | 程度范围 | 影响 |
|------|------|---------|------|
| **主要执念** | 1 个 | 50-100 | **强驱动** → 影响行为决策、触发事件 |
| **次要执念** | 0-2 个 | 20-50 | **弱驱动** → 背景影响、不主导 |
| **无执念**（默认） | 0 | 0 | 按 10 号性格五行驱动 |

**举例**（典型角色配置）：
- 复仇型剑客：主要=复仇（85）+ 次要=强化（40）+ 自由（30）
- 问道型隐士：主要=问道（90）+ 次要=悟道（60）
- 商业型散修：主要=积财（80）+ 次要=享乐（50）+ 归属（25）

---

## 四、数值（0-100 程度值）

每个执念 = 0-100 数值：

| 范围 | 程度 | 行为影响 |
|------|------|---------|
| 0-20 | **淡漠** | 不影响行为 |
| 21-50 | **潜在** | 暗中影响决策倾向 |
| 51-80 | **明确** | 有意识地追求 |
| 81-100 | **狂热** | **驱动一切**（可能做出极端行为） |

## 五、触发器（事件 → 执念变化）

| 事件 | 影响执念 |
|------|---------|
| **突破成功** | 强化 +10 / 求知 +5 |
| **突破失败** | 强化 -15 / 自由 +5（想逃避）/ 复仇 +5（迁怒） |
| 战斗胜利 | 求名 +3 / 复仇 +5（针对仇人） |
| 战斗失败 | 强化 -3 / 复仇 +5（针对仇人） |
| 死亡/濒死 | 自由 +10（想解脱）/ 归属 -10 |
| 际遇·奇遇 | 按事件影响相关执念 |
| 时间流逝 | 主要执念自然 +1/30 天 |

## 六、执念 → 行为/属性影响（部分示例）

| 执念 | 程度 | 效果 |
|------|------|------|
| **强化** | > 80 | 修炼效率 +15% / 突破成功率 +10% |
| **强化** | < 20 | 修炼效率 -10% / 倾向放弃 |
| **复仇** | > 80 | 对仇人战意 B 致死 +20% / 忽略其他目标 |
| **自由** | > 80 | 拒绝任何束缚（拒绝师门任务、拒绝组队） |
| **问道** | > 80 | 主动触发"悟道"事件 / 修炼终极 |
| **享乐** | < 20（被压制） | 易触发"消沉"状态（所有执念 -20%） |
| **强化** + **复仇** | 双高 | "为了复仇而变强"（经典修仙模板） |
