## 四、三层架构 · 行为驱动关系

```
┌──────────────────────────────────────────────────────────┐
│ 性格 / 灵魂 / 肉体（10 号 · v1.0 锁定）                   │
│  ▸ 基础属性 · 相对稳定（0-100 数值）                    │
│  ▸ 火·热血 / 火·果断 / 火·迅捷 等 25 词                │
└──────────────────────────────────────────────────────────┘
                          ↓ 影响（性格"加权"精神状态）
┌──────────────────────────────────────────────────────────┐
│ 精神状态（15 号 · 本系统）                              │
│  ▸ 临时状态 · 随事件变化（持续几周到几月）              │
│  ▸ 9 个状态（3×3 矩阵）                                │
└──────────────────────────────────────────────────────────┘
                          ↓ 影响（精神状态加成战意倾向）
┌──────────────────────────────────────────────────────────┐
│ 战意（13 号 · v0.2 锁）                                 │
│  ▸ 战斗决策 · 每回合选                                  │
│  ▸ 11 类 A-K                                            │
└──────────────────────────────────────────────────────────┘
```

**综合公式**（v0.1 草案）：
```
战意倾向 = 性格基础 + 灵魂修正 + 精神状态加成 + 战意切换成本
```

## 五、属性来源详细表

### 5.1 基础身份（02 号）

| 字段 | 类型 | 说明 |
|------|------|------|
| 寿元 (lifespan) | number | 当前剩余寿元（单位：年） |
| 性别 (gender) | Gender | 'male' / 'female' |
| 容貌 (appearance) | number | 容貌数值（影响人际/奇遇判定） |

### 5.2 修炼状态（02 号 v1.1）

| 字段 | 类型 | 说明 |
|------|------|------|
| 境界 (realm) | Realm | 5 阶（炼气/筑基/金丹/元婴/化神） |
| 修为讲法 | string | 引气/固基/凝丹/结婴/炼神（已锁） |
| 当前修为 (cultivation) | number | 累积修为值 |
| 修为上限 (cultivationMax) | number | 受境界影响 |
| 下一阈值 (nextThreshold) | number | 提升所需 |

### 5.3 灵根与五行（02 号）

| 字段 | 类型 | 说明 |
|------|------|------|

| 7 因子灵根 (spiritRoots) | Record | 乾+坤+火+水+木+金+土（影响灵气吸收） |
