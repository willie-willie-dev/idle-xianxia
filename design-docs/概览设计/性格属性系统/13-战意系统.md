# 战意系统 - 详细设计文档

> 版本：v0.1（草案）
> 状态：规划中
> 关联项目：登仙 Idle Xianxia
> 上游：`10-角色性格属性系统.md`（灵魂五行）
> 下游：`../战斗系统/12-多对多卡牌战斗框架.md`（战斗行为驱动）

---

## 一、模块定位

战意系统是**灵魂五行的战斗应用层**，驱动「角色在战斗中想要达成什么目的」。

- 上游：灵魂五行（`10-角色性格属性系统.md`）提供灵魂响应维度（果断/变通/执着/刚毅/隐忍）
- 本层：11 类战意偏好，按灵魂五行映射，形成战斗中的行为倾向
- 下游：`12-多对多卡牌战斗框架.md` 的「战斗响应」原则引用战意，影响出牌偏好与卡组结构

> **同源五行、各有主战场**：战意系统是灵魂「人际/战斗响应」主战场的具体化，不与性格（事件价值取向）、肉体（身法体质）混用。

---

## 二、设计原则

1. **战意驱动偏好，不驱动数值**：战意决定「倾向于选择哪类行为」，不由它直接结算伤害/效果
2. **同类互斥，跨类可叠加**：角色同一时刻只执行一种战意类别（主战意），但可带辅助倾向（次战意）
3. **战意转换可被干预**：敌方行为、突发事件可触发战意切换（如「威慑」可能让对方从 A 类转入 F 类）

## 三、11 类战意偏好

| # | 类别 | 关键词 | 典型场景 |
|---|------|--------|----------|
| **A** | **击败/破坏** | 击败、击倒、压制、毁物、损装备 | 解除对方战斗力；不一定要杀 |
| **B** | **致死** | 杀死、诛杀、绝杀、**同归于尽**（自损/与敌俱灭类极端手段） | 彻底终结对方存在（含与敌俱灭） |
| **C** | **心理压制** | 降服、威慑、恐惧、轻蔑、戏耍、激将、羞辱 | 不杀，但打掉对方战意 |
| **D** | **利用/榨取** | 奴役、搜魂、逼问、吸取、夺了就走 | 不杀，榨取对方价值 |
| **E** | **防御/守护** | 防御、闪避、守护(他人)、死守(据点/他人) | 保护自己或特定目标 |
| **F** | **战略机动** | 逃跑、撤退、蓄力、蓄势、诱敌 | 以退为进、等待时机 |
| **G** | **情报/侦察** | 观察、试探、刺探 | 获取对方信息/底牌 |
| **H** | **沟通/外交** | 谈判、喊话、要挟、劝降、警告 | 用语言代替或辅助行动 |
| **I** | **投降/求和** | 投降、议和、求饶 | 主动终止战斗（自己放下武器） |
| **J** | **诈败/佯退** | 诈降、假降、诈败、佯退 | 伪装成投降/败退，实际另有目的 |
| **K** | **陷阱/诡计** | 陷阱、诡计、机关、布阵 | 预设条件触发的伏击式战法 |

### 战意类别关系图

```
战意类别
  │
  ├── 攻击导向 ────── A(击败) / B(致死) / C(心理) / D(榨取)
  ├── 控制导向 ────── J(诈败) / K(陷阱)
  ├── 防御导向 ────── E(防御) / F(机动) / I(投降)
  ├── 情报导向 ────── G(侦察)
  └── 外交导向 ────── H(沟通)
```

## 四、灵魂五行映射

> 灵魂五行来自 `10-角色性格属性系统.md` v1.0（锚定词 + 灵魂词）。
> 战意偏好按「主要灵魂 + 次要灵魂」两级映射，取锚定词作为校准依据。

| 战意类别 | 主要灵魂 | 次要灵魂 | 锚定回溯 |
|----------|----------|----------|----------|
| **A. 击败/破坏** | 火·果断 + 金·刚毅 | — | 激进外推（果断）+ 坚硬压制（刚毅） |
| **B. 致死** | 火·果断 + 金·刚毅 | 木·执着 | 激进决绝 + 追杀不放；同归于尽 → 决绝到极致 |
| **C. 心理压制** | 水·变通 + 土·隐忍 | 火·果断 | 渗入心理（变通）+ 积蓄后压（隐忍）+ 果断威慑 |
| **D. 利用/榨取** | 水·变通 + 木·执着 | — | 渗入榨取（变通）+ 不放（执着） |
| **E. 防御/守护** | 土·隐忍 + 金·刚毅 | — | 守住（隐忍）+ 不弯（刚毅） |
| **F. 战略机动** | 水·变通 + 土·隐忍 | — | 顺势绕路（变通）+ 蓄势待机（隐忍） |
| **G. 情报/侦察** | 水·变通 + 木·执着 | — | 渗入刺探（变通）+ 盯梢不放（执着） |
| **H. 沟通/外交** | 水·变通 + 木·执着 | — | 渗入连接（变通）+ 持续经营（执着） |
| **I. 投降/求和** | 土·隐忍（极端） | — | 忍到极致后的主动终结 |
| **J. 诈败/佯退** | 水·变通 + 火·果断 | — | 顺势演技（变通）+ 反击果决（果断） |
| **K. 陷阱/诡计** | 水·变通 + 金·刚毅 | 木·执着 | 巧思布局（变通）+ 精工设置（刚毅）+ 长线埋线（执着） |

### 水·变通覆盖最广的说明

水·变通覆盖了 C/D/F/G/H/J/K 共 7 个类别——这是合理的，因为「换路、绕招、顺势」本身就是水的底色，在战术层面大量表现为灵活性策略。

### 五行 × 战意 分布总览

| 五行 | 覆盖的战意类别 |
|------|----------------|
| **火·果断** | A / B / C(次) / J(次) — 主动、决绝、快速 |
| **水·变通** | C / D / F / G / H / J / K — 灵活、渗透、顺势 |
| **木·执着** | B(次) / D / G / H / K(次) — 持续、盯住、长线 |
| **金·刚毅** | A / B / E / K(主) — 坚硬、压制、守护 |
| **土·隐忍** | C(次) / E / F / I — 积蓄、守住、忍极限 |

## 五、与灵魂五行的接口

战意偏好的灵魂映射通过以下方式与角色灵魂属性联动：

1. **角色灵魂属性**（果断/变通/执着/刚毅/隐忍）取最高值 + 次高值
2. 最高灵魂对应主战意类别，次高对应次战意类别
3. 例如：灵魂「火·果断」最高的角色 → 主动外推型战意（A/B/J）
4. 例如：灵魂「水·变通 + 土·隐忍」双高的角色 → 灵活防御型（F/E/C）

## 六、与战斗系统的接口

`12-多对多卡牌战斗框架.md` 的「战斗响应」原则引用战意：

- **出牌偏好**：主战意类别决定优先打出哪类效果卡
- **卡组倾向**：战意类别影响允许装入的卡牌类型（类型限制规则待后续拍板）
- **响应触发**：对方战意可被己方行为干预（如威慑→恐惧→F类逃跑）
