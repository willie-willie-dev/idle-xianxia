## 一、模块定位

战意系统是**角色在战斗中的意愿决策层**。

### 关键边界

| 层 | 文档 | 职责 |
|---|------|------|
| **意愿层** | **13 号（本系统）** | 「想做什么」—— **决策** |
| **执行层** | 14 号战斗 | 「具体怎么做」—— 释放哪个神通、怎么算伤害 |

> **战意系统不决定具体战斗技巧**（那是 14 号 §七 神通系统的事）；战意只决定"战斗意图"，由 14 号战斗循环执行。

### 核心架构（v0.2 锁定）

```
1. 战力评估（客观 · 3 指标 1:1:1）
   ├── 对方 HP% vs 我方 HP%
   ├── 对方境界 vs 我方境界
   └── 对方上一招 vs 我方上一招（技能差）
        ↓
2. 战力对比 V（综合 [-100, +100]）
        ↓
3. 性格过滤（主观 · 性格阳阴 10 维）
        ↓
4. 预设映射表（性格 → 战意）
        ↓
5. 战意输出（11 类临时标签 · 具体语义后定）
        ↓
6. → 14 号执行（按行动类型）
```

### 与灵魂/肉体五行的关系

- **性格阳阴（10 维）** → 决定战意**决策倾向**（v0.2 锁定 · 本系统使用）
- **灵魂五行** → 决定战意**偏好**（上游 10 号锁定，13 号不直接用）
- **肉体五行** → 已在 14 号用作抗性维度 + 神通加成（不在 13 号重复使用）

## 二、11 类战意（**临时标签集 · 具体语义后定**）

> **v0.2 关键降级**：11 类战意作为**临时输出标签**保留；具体语义（如投降触发条件、诈败判定、同归定义）**留框架稳定 + 实战测试后再设计**。

### 2.1 进攻意愿（A/B/C/D）

| 战意 | 含义 | 典型场景 |
|------|------|----------|
| **A 击败** | 想击败对方 | 解除对方战斗力；不一定要杀 |
| **B 致死** | 想致死（含**同归于尽**极端态） | 彻底终结对方存在 |
| **C 心理** | 心理压制（轻蔑、戏耍、激将、**鄙视**） | 不杀，打掉对方战意 |
| **D 榨取** | 榨取价值（奴役、搜魂、逼问、吸取） | 不杀，榨取对方价值 |

### 2.2 控制意愿（J/K）

| 战意 | 含义 |
|------|------|
| **J 诈败** | 伪装投降 / 假装撤退（实际是诱敌） |
| **K 陷阱** | 预设条件触发的伏击式战法 |

### 2.3 防御/逃跑意愿（E/F）

| 战意 | 含义 |
|------|------|
| **E 防御** | 保护自己或特定目标（防御、闪避、**守护**他人/据点） |
| **F 机动** | 逃跑、撤退、蓄力、诱敌、**逃走** |

### 2.4 终止意愿（G/H/I）

| 战意 | 含义 |
|------|------|
| **G 侦察** | 观察、试探、刺探（再看看） |
| **H 沟通** | 谈判、喊话、要挟、劝降、警告、**放过** |
| **I 投降** | 主动终止战斗（放下武器）、**投降** |

### W 提的 4 个"非攻击意愿"已覆盖确认

| W 例子 | 对应战意 | 含义 |
|--------|---------|------|
| 逃走 | **F 机动** | 想跑 / 调整 |
| 投降 | **I 投降** | 想终止战斗 |
| 鄙视 | **C 心理** | 心理压制（轻蔑、戏耍、激将） |
| 放过 | **H 沟通** | 想谈 / 劝降 / 警告 |

> 11 类已覆盖 W 提的 4 个核心"非攻击意愿"——**不用新增子类**。

## 三、战意决策框架（v0.2 核心 · 新增）

### 3.1 战力评估 · 3 指标

每回合开始时，系统收集以下数据：

| 指标 | 数据来源 | 范围 |
|------|----------|------|
| **HP%** | 14 号 HP 字段 | 0-100% |
| **境界** | 02 号境界（5 阶：炼气/筑基/金丹/元婴/化神） | 1-5 |
| **技能** | 14 号上一回合释放的神通 ID / 行动类型 | 字符串 |

### 3.2 战力对比 · 1:1:1 权重（v0.2 锁定）

3 指标按 **1:1:1** 权重合成战力对比：

```
V = (HP_normalized × 0.33) + (境界_normalized × 0.33) + (技能_normalized × 0.33)
V 范围: [-100, +100]
V > 0 = 我方优势; V < 0 = 我方劣势; V = 0 = 均势
```

**HP 差**：

```
HP差 = 我方HP% - 对方HP%   范围: [-100, +100]
```

**境界差**：

```
境界差 = 我方境界阶 - 对方境界阶   范围: [-4, +4]（5 阶共 4 差）
归一化: 境界差_normalized = 境界差 / 4 × 100   范围: [-100, +100]
```

**技能差**（v0.2 草案 · 待精调）：

```
技能差 = 对方上一招造成的伤害 - 我方上一招造成的伤害
归一化: 技能差_normalized = clamp(技能差 / max_damage × 100, -100, +100)
```

### 3.3 性格过滤 · 仅性格阳阴 10 维（v0.2 锁定）

**性格过滤范围 = 仅性格阳阴（10 维）**—— 跟"性格"语义一致；不跟 14 号的 5 维响应值重复使用。

10 维性格阳阴（10 号 §五）：

| 五行 | 阳面 | 阴面 |
|------|------|------|
| 火 | 热血 | 贪婪 |
| 水 | 包容 | 沉溺 |
| 木 | 传承 | 侵夺 |
| 金 | 守正 | 冷酷 |
| 土 | 厚德 | 吝啬 |

**过滤逻辑**：
- 取**最高阳 + 最高阴**（10 维里取 2 个最高的性格维度）
- 这 2 个性格维度 → 决定战意倾向
- 例：火·阳·热血最高 → 倾向 A 击败 / B 致死

### 3.4 预设映射表（v0.2 锁定）

| 性格维度（最高） | 倾向战意（候选集） |
|------------------|------------------|
| 火·阳·热血 | **A 击败** / B 致死 |
| 火·阴·贪婪 | **D 榨取** / A 击败 |
| 水·阳·包容 | **H 沟通** / E 防御 |
| 水·阴·沉溺 | **C 心理** / H 沟通（不愿放手） |
| 木·阳·传承 | **B 致死**（守护珍视） / D 榨取 |
| 木·阴·侵夺 | **D 榨取** / A 击败 |
| 金·阳·守正 | **E 防御**（守住底线） / B 致死（不屈） |
| 金·阴·冷酷 | **B 致死** / D 榨取（不择手段） |
| 土·阳·厚德 | **E 防御**（守护他人） / I 投降（自我牺牲） |
| 土·阴·吝啬 | **F 机动** / I 投降（保命） |

### 3.5 决策流程（v0.2 简化版）

```
1. 战力评估 → V ∈ [-100, +100]
2. 性格过滤 → 取最高阳 + 最高阴（共 2 个性格维度）
3. 查预设映射表 → 候选战意集合（2-3 个）
4. 根据 V 选最匹配的战意：
   - V > +30（我方大优势）→ 候选战意中选"攻击/控制型"（A/B/C/D/J/K）
   - V ∈ [-30, +30]（均势）→ 候选战意中选"控制/防御型"（J/K/E/F）
   - V < -30（我方大劣势）→ 候选战意中选"防御/终止型"（E/F/G/H/I）
5. 战意确定 → 输出 → 14 号执行
```

### 3.6 简化版 AI 示例

```
if V > +30 and 性格最高 = 火·阳·热血:
    战意 = A 击败（追击）
elif V > +30 and 性格最高 = 水·阴·沉溺:
    战意 = C 心理（玩弄）
elif V ∈ [-30, +30] and 性格最高 = 金·阳·守正:
    战意 = E 防御（守住）
elif V < -30 and 性格最高 = 土·阳·厚德:
    战意 = I 投降（自我牺牲）
elif V < -30 and 性格最高 = 火·阴·贪婪:
    战意 = F 机动（保命要紧）
else:
    战意 = 候选战意集合中按随机选
```

> 实际决策需要更多维度（战意类别、对手战意、随机性等），v0.2 先给简化版，复杂 AI 留 §六 开放点。

## 四、战意切换机制（沿用 v0.2）

### 4.1 触发条件

每回合开始时，**重新跑决策框架**（§三）→ 得出当前战意。

### 4.2 切换成本 · 修为消耗 5%/次（v0.2 草案，待精调）

如果新战意 ≠ 当前战意：

```
战意切换成本 = 修为当前值 × 5%
```

**设计意图**：
- 频繁切换 = 高修为消耗
- 让"战意稳定"成为经济优势
- 跟 14 号周天"代价哲学"一致

### 4.3 切换频率

**每回合 1 次**（每回合开始时跑一次决策框架，决定战意）。

## 五、战意 → 14 号 接口（沿用 v0.2）

### 5.1 行动类型映射

| 13 号战意 | 行动类型 | 14 号执行 |
|----------|----------|-----------|
| A 击败 / B 致死 / C 心理 / D 榨取 | **攻击型** | 释放攻击型神通 |
| J 诈败 / K 陷阱 | **控制型** | 释放控制型 / 设置陷阱 |
| E 防御 / F 机动 | **防御/逃跑型** | 释放防御型 / 尝试脱离战斗 |
| G 侦察 / H 沟通 / I 投降 | **终止型** | 侦察 / 沟通 / 投降（战斗终止） |

### 5.2 关键边界

- 13 号**只**决定"行动类型"
- 13 号**不**决定"具体哪个神通"
- 具体神通由 14 号根据角色已学神通 + 行动类型匹配
