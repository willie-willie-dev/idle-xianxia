## 基础属性

角色的表层身份与生存状态字段。与战斗六维（hp/mp/atk 等）解耦，独立存储与展示。

| 属性 | 字段（建议） | 类型 | 说明 |
|------|-------------|------|------|
| 寿元 | `lifespan` | `number` | 当前剩余寿元（单位：年，精确规则待定） |
| 境界 | `realm` | `Realm` | 修为境界，如炼气 / 筑基 / 金丹 / … |
| 性别 | `gender` | `Gender` | `'male' \| 'female'` |
| 容貌 | `appearance` | `number` | 容貌数值，影响人际/奇遇相关判定（具体规则待定） |

### 数据结构

```typescript
type Gender = 'male' | 'female';

type Realm =
  | '炼气' | '筑基' | '金丹' | '元婴' | '化神'
  | '合体' | '大乘' | '渡劫' | '仙人';

// Character 中的基础属性字段（节选）
interface CharacterBaseAttrs {
  lifespan: number;    // 寿元
  realm: Realm;        // 境界
  gender: Gender;      // 性别
  appearance: number;  // 容貌
}
```

### 字段说明

#### 寿元（`lifespan`）

- 表示角色当前剩余寿元
- 与境界、修炼、奇遇等可能存在联动（减寿 / 增寿 / 突破延寿），细则待定
- 寿元归零的处理（陨落 / 转世等）待定

#### 境界（`realm`）

- 角色当前修为境界标签
- 本文件仅将其定义为**基础属性字段**；突破流程、阶段划分、容量倍率等不在本文展开

#### 性别（`gender`）

- 创建角色时选定，默认 `'male'`
- 展示文案：`male → 男`，`female → 女`（`GENDER_LABELS`）

#### 容貌（`appearance`）

- 数值型属性，初始值与成长规则待定
- 预期主要参与人际类 / 奇遇类事件判定，不直接进入战斗伤害公式

| `gender` | ✅ 代码侧已有（创建角色可选） |

## 灵根与五行

### 设计规格

**本模块实际包含两套相关但独立的灵根系统：**

#### 系统A：五行灵根（`element`，用于属性成长倍率）

- 五行类型（`WuXing`）：`metal | wood | water | fire | earth`
- 在最终属性计算中参与乘法修正（若该公式仍保留）
- 创建角色时由玩家选择（或默认 `metal`）

```typescript
/**
 * 五行成长倍率：按「相生」哲学设计
 * 相生链：木→火→土→金→水→木
 * - 木生火 → 木灵根强化火属性（atk/spd）
 * - 火生土 → 火灵根强化土属性（def/hp）
 * - 土生金 → 土灵根强化金属性（atk/spd）
 * - 金生水 → 金灵根强化水属性（mp/wil）
 * - 水生木 → 水灵根强化木属性（hp/mp）
 */
const WUXING_GROWTH: Record<WuXing, Partial<Stats>> = {
  metal: { mp: 1.3, wil: 1.1 },  // 金生水 → 法力、神识
  wood:  { atk: 1.3, spd: 1.1 }, // 木生火 → 攻击、速度
  water: { hp: 1.3, mp: 1.1 },   // 水生木 → 生命、法力
  fire:  { def: 1.3, hp: 1.1 },  // 火生土 → 防御、生命
  earth: { atk: 1.3, spd: 1.1 }, // 土生金 → 攻击、速度
};
```

#### 系统B：七因子灵根分布（`spiritRoots`，用于灵气亲和与道种系统）

- **7种灵根**（`SpiritRootKey`）：`qian`(乾)、`kun`(坤)、`fire`(火)、`water`(水)、`wood`(木)、`metal`(金)、`earth`(土)
- 总和必须为 100（百分比）
- 灵根影响角色对各类灵气的亲和力（道种系统读取）
- **坤灵根特殊规则**：`kun = 100 - sum(其他六项)`，自动计算

**默认均分**（`defaultEvenSpiritRoots`）：

| 灵根 | qian(乾) | kun(坤) | 火   | 水   | 木   | 金   | 土   |
|------|----------|---------|------|------|------|------|------|
| 占比 | 15%      | 10%     | 15%  | 15%  | 15%  | 15%  | 15%  |

### 数据结构

```typescript
// SpiritRootKey 的7种
type SpiritRootKey = 'qian' | 'kun' | 'fire' | 'water' | 'wood' | 'metal' | 'earth';

// spiritRoots：Record<SpiritRootKey, number>，总和100
spiritRoots: { qian: 15, kun: 10, fire: 15, water: 15, wood: 15, metal: 15, earth: 15 }

// element：WuXing，五行灵根（影响属性成长倍率）
element: WuXing;
```

| 五行 | 灵魂（神识能力） | 肉体（身法/体质） | 魂↔体呼应 |
|------|------------------|-------------------|-----------|

**定名说明：**

- **木·灵魂 → 执着** + **木·肉体 → 生机**：合适，不冲突。执着落在「不放弃」的念头层，生机落在肉身活力层，形成「心不死 / 身有生机」。镜像不如火「果断↔迅捷」那样整齐，但语义通顺；且把「执着」留给木后，金可干净地用「刚毅 / 坚韧」。
- **金·灵魂 → 刚毅** + **金·肉体 → 坚韧**：志之刚正有力 ↔ 体之坚而能韧。性格金阳已改为「守正」，与灵魂「刚毅」不再同名（详见 `10-角色性格属性系统.md`）。
- **土·灵魂 → 隐忍**（替换原「坚忍」）：专表忍耐——压住不发、默默承受；避免与金体「坚韧」音形义过近。备选：耐性、承载。

### 五行性格系统

#### 设计规格

五行性格是角色的行事偏好体系，独立于修为灵根（`element`），不影响属性数值，只影响事件决策倾向。

##### 结构（10维）

每个五行方向有**阳**和**阴**两个独立数值，下限 0，上限不封顶：

| 五行 | 阳面 | 阴面 |
|------|------|------|
| 火 | 热血（主动、热情）| 贪婪（索取、占有）|
| 水 | 包容（忠贞接纳）| 沉溺（失度渗入、难以抽身）|
| 木 | 传承（延续珍视之物）| 侵夺（以扩展侵占他人根基）|
| 金 | 守正（守正道、有所不为）| 冷酷（不择手段）|
| 土 | 厚德（牺牲、给予）| 吝啬（自私、占有）|

##### 与修为灵根的关系

两套独立系统，无直接绑定。

- **修为灵根（`element`）**：定义五行主灵根，影响属性成长倍率
- **五行性格（`fiveElements`）**：定义行事偏好，影响事件选项倾向

两者的关系：**修为灵根作为五行性格的初始锚点**，角色创建时由角色系统根据 `element` 生成初始值；后续由事件选项结算持续修正，修正结果不受修为灵根约束。

##### 初始化

初始化逻辑由角色系统在创建角色时执行，框架文档只描述接口规范。

`GeneratorContext.fiveElements` 字段在角色创建时由角色系统写入 `Character` 对象。

##### 修正机制

每次事件选项结算时：

1. 根据选项的 `temperamentShift` 字段应用偏移
2. 将偏移量叠加到对应的五行性格维度上
3. 数值下限 0，上限不封顶（超过 100 继续增长）
4. 无衰减机制（性格一旦形成不回落）

##### 性格偏移接口

性格偏移由事件模板自行定义，角色系统只提供接口规范。

**接口格式：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `dimension` | `FiveElementsDimension` | 偏移的五行维度，如 `fire.yang`、`water.yin` |
| `value` | `number` | 偏移量，通常为 ±1 |

**可用维度：**

| dimension 值 | 对应阴阳 | 说明 |
|-------------|---------|------|
| `fire.yang` | 火·阳 | 热血 |
| `fire.yin` | 火·阴 | 贪婪 |
