# 修炼子系统设计 v1.0

> 版本：v1.0（整合功法+周天）
> 状态：规划中
> 上级系统：角色系统
> 说明：本系统由原「周天与功法系统」重构而来，将功法与周天合并为统一的修炼子系统。

---

## 一、定位

修炼子系统是**角色系统**的子模块，与「角色属性子系统」「装备子系统」平级。

**与其他子系统的关系：**
- 角色属性子系统决定角色的基础成长（境界/五行/等级）
- 修炼子系统在角色属性基础上，管理功法和周天运转，影响灵气吸收效率
- 装备子系统提供额外属性加成，与修炼子系统并列加成于最终面板

---

## 二、核心架构

```
┌─────────────────────────────────────────────────────────┐
│                     五 个 修 炼 槽 位                    │
│                                                         │
│  [角亢·东]   [井鬼·南]   [紫薇·中]   [奎娄·西]   [斗牛·北]  │
│                                                         │
│   木            火         周天           金            水      │
│   预留          预留       唯一生效       预留          预留      │
└─────────────────────────────────────────────────────────┘
```

**五槽即五功法。** 每个槽位可装备一部功法，功法本身携带属性加成和固定开销。

## 四、功法数据字段

每部功法包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 功法名称 |
| `基础比例` | float | 灵根吸收基础比例 |
| `基础固定值` | int | 灵根吸收基础固定加成 |
| `Bonus比例` | float | 额外加成比例 |
| `Bonus固定值` | int | 额外加成固定值 |
| `固定开销-灵根种类` | SpiritRootKey | 消耗的灵根类型：乾坤/火/水/木/金/土 |
| `固定开销-数值` | int | 对应灵根种类的消耗数值 |
| `属性加成` | Partial\<Stats\> | 功法提供的永久属性加成（如 atk+10） |
| `反噬效果` | object | 预留机制，暂不展开 |

### 4.1 灵根种类（7种）

- `qian`（乾白）
- `kun`（坤黑）
- `fire`（火）
- `water`（水）
- `wood`（木）
- `metal`（金）
- `earth`（土）

### 4.2 固定开销

每次激活功法时，消耗**指定灵根种类**的灵气：

```
消耗 = 对应灵根种类的灵气数值
如果角色该灵根种类为 0 或不存在 → 无法激活功法（不吸收）
```

### 4.3 反噬效果（预留）

触发条件：固定开销值无法被满足时自动触发。具体条例待设计。

## 五、紫薇位（周天运转中枢）

### 5.1 紫薇位的作用

紫薇（中位）是周天运转的核心位置：
- 四方灵气汇聚后的周天循环计算
- 道种提炼效率的结算
- **唯一生效**：东南西北四象位置为预留槽位，当前仅有紫薇位实际生效

### 5.2 周天运转流程

```
灵气吸收 → 紫薇位中枢运转 → 功法固定开销扣除（按灵根种类） → 道种提炼
```

## 六、与角色系统的集成

### 6.1 修炼子系统 → 角色最终属性

功法提供的 `属性加成` 字段，汇总到角色 `bonusFromCultivation`（或直接并入现有加成层）：

```
最终属性 = 基础属性 × 境界倍率 × 五行倍率
         + 装备加成 + 技能加成 + 奇遇加成 + 修炼加成
```

### 6.2 角色系统数据结构

```typescript
interface Character {
  // ... 现有字段
  cultivation: CultivationSlots;  // 修炼槽位
}

interface CultivationSlots {
  east: CultivationBase | null;   // 角亢·东（木）
  south: CultivationBase | null;  // 井鬼·南（火）
  center: CultivationBase | null; // 紫薇·中（周天，唯一生效）
  west: CultivationBase | null;   // 奎娄·西（金）
  north: CultivationBase | null;  // 斗牛·北（水）
}

interface CultivationBase {
  id: string;
  name: string;
  element: SpiritRootKey;
  baseRatio: number;
  baseFixed: number;
  bonusRatio: number;
  bonusFixed: number;
  costType: SpiritRootKey;
  costValue: number;
  statBonus: Partial<Stats>;
  backlash: object | null;
}
```
