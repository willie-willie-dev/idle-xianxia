## 一、定位

修炼子系统是**角色系统**的子模块，与「角色属性子系统」「装备子系统」平级。

**与其他子系统的关系：**
- 角色属性子系统决定角色的基础成长（境界/五行/灵根）
- 修炼子系统在角色属性基础上，管理**5 个功法槽位** + **大小周天运转** + **灵气/修为流转**
- 装备子系统提供额外属性加成，与修炼子系统并列加成于最终面板

## 二、核心架构 · 5 槽 × 2 周天 矩阵

### 2.1 5 个功法槽位（保留五行方位）

| 方位 | 星宿 | 五行 | 状态 |
|------|------|------|------|
| **东** | 角亢 | 木 | 预留 |
| **南** | 井鬼 | 火 | 预留 |
| **中** | 紫薇 | 土 | **唯一生效 · 周天运转中枢** |
| **西** | 奎娄 | 金 | 预留 |
| **北** | 斗牛 | 水 | 预留 |

### 2.2 每槽对大小周天都有 % 效率影响（v2.0 核心）

每部功法装备到槽位后，**同时**对**小周天**和**大周天**有百分比效率贡献：

```
5 槽位 →  各槽功法 →  小周天 X%  +  大周天 Y%

  [角亢·东]  功法 A → 小周天 X₁%  + 大周天 Y₁%
  [井鬼·南]  功法 B → 小周天 X₂%  + 大周天 Y₂%
  [紫薇·中]  功法 C → 小周天 X₃%  + 大周天 Y₃%   ← 当前唯一生效
  [奎娄·西]  功法 D → 小周天 X₄%  + 大周天 Y₄%
  [斗牛·北]  功法 E → 小周天 X₅%  + 大周天 Y₅%

小周天总效率 = X₁ + X₂ + X₃ + X₄ + X₅
大周天总效率 = Y₁ + Y₂ + Y₃ + Y₄ + Y₅
```

**关键含义**：
- 不是"槽位功能化"（小周天/大周天各占一个槽）
- 而是"**槽位叠加**"——每个槽位都对两个周天有 % 效率贡献
- 当前 1 槽生效 = 1 套效率；未来 5 槽全开 = 5 套效率叠加
- 槽位 1-4 预留 = 占位 / 未激活 / 0 效率

## 四、功法字段（v2.0 概念化 · 删伪代码）

> v2.0 删除 v1.0 的 `interface CultivationBase` 等 TypeScript 伪代码，改为**概念字段**。

每部功法有 **5 个概念字段**：

| 概念字段 | 含义 |
|---------|------|
| **名称** | 功法名字 |
| **所属五行** | 火 / 水 / 木 / 金 / 土（影响跟角色灵根的亲和度） |
| **小周天效率 %** | 该功法装备到槽位后，对**小周天**（吸收+储存）的效率贡献 |
| **大周天效率 %** | 该功法装备到槽位后，对**大周天**（灵气→修为）的效率贡献 |
| **属性加成** | 给角色提供的永久属性加成（如 atk+10, def+5） |

> **v2.0 简化说明**：v1.0 的"基础比例/基础固定值/Bonus比例/Bonus固定值/固定开销-灵根种类/固定开销-数值/反噬效果"等字段**全部删除**——先专注"5 槽 × 2 周天"的核心矩阵概念；反噬、固定开销等机制留待后续 v2.x 设计。

## 五、大小周天运转（v2.0 核心 · 重写）

### 5.1 小周天（吸收端 · 持续自动）

| 项 | 设计 |
|-----|------|
| **输入** | 外界灵气（奇遇/时间流逝/修炼事件） |
| **流程** | 按 7 灵根比例分配（沿用灵气 v2.0 规则） |
| **输出** | 7 灵根灵气池（独立池） |
| **效率** | = Σ(5 槽位小周天 % 贡献) |
| **触发** | **自动**（持续运转，受灵根/功法/环境灵气浓度影响） |
| **当前** | 紫薇位唯一生效（1 槽贡献） |

### 5.2 大周天（转化端 · 主动触发）

| 项 | 设计 |
|-----|------|
| **输入** | 7 灵根灵气池 |
| **流程** | 灵气 → **修为**（注：v1.0 称为「道种」，v2.0 统一为「修为」） |
| **效率** | = Σ(5 槽位大周天 % 贡献) |
| **损耗** | **5%**（沿用 14 号 v0.2 §6.4 草案） |
| **触发** | **主动**（玩家/AI 触发「运转大周天」动作） |
| **当前** | 紫薇位唯一生效（1 槽贡献） |

### 5.3 大周天反向（应急 · 主动触发）

| 项 | 设计 |
|-----|------|
| **输入** | 修为（碎境释放） |
| **输出** | 7 灵根灵气池 |
| **效率** | = Σ(5 槽位大周天 % 贡献) |
| **损耗** | **70%**（沿用 14 号 v0.2 §6.4 草案，应急代价高） |
| **触发** | 战斗应急（手动触发） |
| **当前** | 紫薇位唯一生效（1 槽贡献） |

### 5.4 大小周天流转图

```
┌─────────────────────────────────────────────────┐

│        ↓                                          │
```
