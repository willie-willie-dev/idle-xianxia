## 一、定位

修炼子系统是**角色系统**的子模块，与「角色属性子系统」「装备子系统」平级。

**与其他子系统的关系：**
- 角色属性子系统决定角色的基础成长（境界/五行/灵根）
- 修炼子系统在角色属性基础上，管理**5 个功法栏位**（全部默认开启）+ **大小周天运转** + **7 灵根池（吸收公式 + 上限公式）** + **池内部分流** + **灵气/修为流转**
- 装备子系统提供额外属性加成

## 二、核心架构 · 5 栏 × 5 类参数 矩阵（v2.0c 简化）

### 2.1 5 个功法栏（v2.0c 简化 · 全部默认开启）

| 栏位 | 方位 | 状态 | 五行绑定 |
|------|------|------|----------|
| 栏 1 | 东 | **默认开启** | **不绑**（仅位置编号） |
| 栏 2 | 南 | **默认开启** | **不绑** |
| 栏 3 | 中 | **默认开启** | **不绑** |
| 栏 4 | 西 | **默认开启** | **不绑** |
| 栏 5 | 北 | **默认开启** | **不绑** |

> **v2.0c 关键简化**（W 拍板）：
> - 5 栏**全部默认开启**（无预留 / 无"紫薇位唯一生效"）
> - 5 栏**不绑五行**——仅位置编号，功法的"所属五行"是**功法属性**

### 2.2 每栏对 5 类参数都有贡献（v2.0b 沿用）

每部功法装备到栏位后，对以下 5 类参数有贡献：

```
5 栏位 →  各栏功法 →  5 类参数

  栏 1（东）  功法 A → 吸收 A₁% + 容纳量 B₁% + 大周天 Y₁% + 降低损耗 Z₁% + 分流 (r₁, c₁)
  栏 2（南）  功法 B → 吸收 A₂% + 容纳量 B₂% + 大周天 Y₂% + 降低损耗 Z₂% + 分流 (r₂, c₂)
  栏 3（中）  功法 C → 吸收 A₃% + 容纳量 B₃% + 大周天 Y₃% + 降低损耗 Z₃% + 分流 (r₃, c₃)
  栏 4（西）  功法 D → 吸收 A₄% + 容纳量 B₄% + 大周天 Y₄% + 降低损耗 Z₄% + 分流 (r₄, c₄)
  栏 5（北）  功法 E → 吸收 A₅% + 容纳量 B₅% + 大周天 Y₅% + 降低损耗 Z₅% + 分流 (r₅, c₅)
```

**5 栏综合（v2.0b 锁定 · 求和 + 钳制 0%-500%）**：
- 吸收比例综合 = clamp(Σ A₁..₅, 0%, 500%)
- 容纳量综合 = clamp(Σ B₁..₅, 0%, 500%)
- 大周天效率综合 = clamp(Σ Y₁..₅, 0%, 500%)
- 大周天降低损耗综合 = clamp(Σ Z₁..₅, 0%, 500%)
- 分流比例（修为）= avg(r₁..₅)
- 分流比例（战斗）= avg(c₁..₅) = 1 - 修为比例

### 2.3 相生加成机制（v2.0c 新增 · W 拍板 a 路线）

**相生链**（沿用 02 号 WUXING_GROWTH）：**木 → 火 → 土 → 金 → 水 → 木**

**检查规则**：
- 检查 4 对相邻：栏 1→2, 栏 2→3, 栏 3→4, 栏 4→5
- 每对相邻栏的功法"所属五行"如果**相生**（前者生后者），则算 1 对相生

**加成计算（a 路线 · 每对 +50%）**：
- 每对相生 → **大小周天效率** +50%（在原有基础上）
- 多个相生对叠加（最多 4 对 = +200%）
- **大小周天效率** = **小周天吸收比例 + 小周天容纳量 + 大周天效率**（**3 个参数**参与相生加成）
- **不包括**：大周天降低损耗、分流比例（这 2 个不参与相生加成）

**加成公式**：
```
相生加成% = 相生对数 × 50%
相生加成后的"大小周天效率" = 综合% × (1 + 相生加成%)
例：1 对相生 = +50% = ×1.5
    2 对相生 = +100% = ×2
    4 对相生 = +200% = ×3
钳制：0%-500%（沿用 5 栏综合钳制）
```

**举例**（5 栏全装，4 对都相生）：
- 栏 1（木）→ 栏 2（火）：木生火 ✅
- 栏 2（火）→ 栏 3（土）：火生土 ✅
- 栏 3（土）→ 栏 4（金）：土生金 ✅
- 栏 4（金）→ 栏 5（水）：金生水 ✅
- → 4 对都相生 → 相生加成 200% → 大小周天效率 ×3

## 四、功法字段（v2.0b 沿用 · 9 个必选字段）

> v2.0 删除 v1.0 的 `interface CultivationBase` 等 TypeScript 伪代码，改为**概念字段**。
> v2.0b 拆"小周天"为 2 个独立参数。

每部功法有 **9 个必选字段**：

| # | 概念字段 | 含义 |
|---|---------|------|
| 1 | **名称** | 功法名字 |
| 2 | **所属五行** | 火 / 水 / 木 / 金 / 土（影响相生加成检查） |
| 3 | **小周天吸收比例 %** | 该功法对**小周天吸收**的贡献（参与相生加成） |
| 4 | **小周天容纳量 %** | 该功法对**灵根池上限**的加成贡献（参与相生加成） |
| 5 | **大周天效率 %** | 该功法对**大周天**（转化速度）的效率贡献（参与相生加成） |
| 6 | **大周天降低损耗 %** | 该功法对**大周天正向损耗**的降低贡献（**不参与相生加成**） |
| 7 | **分流比例** | 该功法对**7 灵根池内部分流**的贡献：修为转化用 % / 战斗调用用 %（r + c = 100%）（**不参与相生加成**） |
| 8 | **逆运 %** | 该功法对**大周天反向**的启用（**不参与相生加成**） |
| 9 | **属性加成** | 永久属性加成 |

## 五、大小周天运转（v2.0c 加相生加成）

### 5.1 小周天（吸收端 · 持续自动 · v2.0c 相生加成）

| 项 | 设计 |
|-----|------|
| **输入** | 外界灵气（奇遇/时间流逝/修炼事件） |
| **吸收公式** | **吸纳量 = 浓度 × 灵根比例 × clamp(Σ 5 栏小周天吸收比例% × (1 + 相生加成%), 0%, 500%) × 乾/坤加成** |
| **池上限公式** | **灵根池上限 = 灵根本身上限 × clamp(Σ 5 栏小周天容纳量% × (1 + 相生加成%), 0%, 500%)** |
| **触发** | **自动** |
| **当前** | 5 栏全部默认开启 |

> **v2.0c 新**：相生加成应用范围 = **小周天吸收比例 + 小周天容纳量**（2 个参数参与相生加成）

### 5.2 大周天（转化端 · 主动触发 · v2.0c 相生加成）

| 项 | 设计 |
|-----|------|
| **输入** | 7 灵根灵气池中**修为转化用部分**（由分流比例决定） |
| **流程** | 灵气（修为用部分） → 修为 |
| **效率** | = clamp(Σ 5 栏大周天效率% × (1 + 相生加成%), 0%, 500%) |
| **损耗** | **默认 100%；实际损耗 = clamp(100% - Σ(5 栏"大周天降低损耗 %"), 0%, 100%)** ← **不参与相生加成** |
| **触发** | **主动**（玩家/AI 触发） |
| **当前** | 5 栏全部默认开启 |

> **v2.0c 新**：相生加成应用范围 = **大周天效率**（1 个参数参与相生加成）。**降低损耗不参与相生加成**。

### 5.3 大周天反向（应急 · 主动触发 · v2.0c 不变）

| 项 | 设计 |
|-----|------|
| **输入** | 修为（碎境释放） |
| **输出** | 7 灵根灵气池中**战斗调用用部分（储备灵气）** |
| **默认状态** | **无法进行**（无"逆运"参数时 0% 转化） |
| **启用** | 装备带"逆运 %"参数的功法后，按"逆运 %"比例转化 |
| **逆运 % 语义** | **极低比例**（如 3%：100 修为 → 3 战斗灵气） |
| **触发** | 战斗应急（手动触发） |

> 逆运不参与相生加成（v2.0c 明确）。

### 5.4 7 灵根池内部分流（v2.0a 沿用）

> 7 灵根池 = 通用池，内部分流为"修为转化用"+"战斗调用用/储备灵气"。
> 分流比例 = 5 栏综合的功法"分流比例"参数的平均（**不参与相生加成**）。
