## 五、大小周天运转（v2.0c 沿用）

### 5.1 小周天（吸收端）

```
吸纳量 = 浓度 × 灵根比例 × clamp(Σ 5 栏小周天吸收比例% × (1 + 相生加成%), 0%, 500%) × 乾/坤加成
灵根池上限 = 灵根本身上限 × clamp(Σ 5 栏小周天容纳量% × (1 + 相生加成%), 0%, 500%)
```

### 5.2 大周天（转化端）

```
效率 = clamp(Σ 5 栏大周天效率% × (1 + 相生加成%), 0%, 500%)
损耗 = clamp(100% - Σ 5 栏降低损耗%, 0%, 100%)  ← 不参与相生
```

### 5.3 大周天反向（应急）

```
默认 0%（无法进行）
逆运 % = 5 栏综合（Σ 5 栏逆运%）（示例：栏 5 = 3%，其他 = 0% → 总 3%）
修为 → 战斗调用用（储备灵气），比例 = 3%
```

### 5.4 7 灵根池内部分流

```
分流（修为）= avg(5 栏分流修为%)
分流（战斗）= avg(5 栏分流战斗%) = 1 - 修为比例
```

### 5.5 完整综合示例（v2.0d 新增 · 5 栏全开 · 3 对相生）

> 演示：玩家装备上面 4.1 的 5 个示例功法（5 栏全开 + 3 对相生）

#### 步骤 1 · 5 栏综合（求和 + 钳制 0%-500%）

| 参数 | 5 栏求和 | 综合值 |
|------|----------|--------|
| 小周天吸收比例 | 20+25+20+15+10 = 90% | **90%** |
| 小周天容纳量 | 25+20+30+15+10 = 100% | **100%** |
| 大周天效率 | 15+25+20+30+10 = 100% | **100%** |
| 大周天降低损耗 | 20+30+25+35+10 = 120% | **120%** |
| 分流（修为） | avg(40,30,50,20,10) = 30% | **30%** |
| 分流（战斗） | avg(60,70,50,80,90) = 70% | **70%** |
| 逆运 | 0+0+0+0+3 = 3% | **3%** |

#### 步骤 2 · 相生加成（3 对 = +150% = ×2.5）

| 参数 | 综合 | × (1 + 150%) | 钳制 0%-500% | 最终 |
|------|------|---------------|--------------|------|
| 小周天吸收比例 | 90% | 90% × 2.5 = 225% | clamp 225% | **225%** |
| 小周天容纳量 | 100% | 100% × 2.5 = 250% | clamp 250% | **250%** |
| 大周天效率 | 100% | 100% × 2.5 = 250% | clamp 250% | **250%** |
| 大周天降低损耗 | 120% | **不参与相生** | — | **120%** |
| 分流 | 30%/70% | **不参与相生** | — | **30%/70%** |

#### 步骤 3 · 实际效果

**小周天吸纳**（假设浓度 100，灵根比例 50%，乾/坤加成 1.0）：
```
吸纳量 = 100 × 50% × 225% × 1.0 = 112.5 灵气单位
```

**灵根池上限**（假设灵根本身上限 2000）：
```
灵根池上限 = 2000 × 250% = 5000
（5 栏全开让上限从 2000 → 5000，提升 2.5 倍）
```

**大周天转化**（输入 100 修为用灵气）：
```
效率 = 250%（高效率转化）
实际损耗 = clamp(100% - 120%, 0%, 100%) = 0%（完美转化，无损耗）
结果：100 灵气 → 100 修为（零损耗！）
```

**池内部分流**（吸纳 100 灵气）：
```
修为转化用 = 100 × 30% = 30 灵气
战斗调用用（储备）= 100 × 70% = 70 灵气
```

**大周天反向（应急）**（假设修为 1000，灵气耗尽）：
```
逆运 % = 3%（栏 5 逆运秘法 3%）
转化 = 1000 × 3% = 30 战斗灵气（注入"战斗调用用"部分）
损耗 = 970 修为（97% 损耗，"燃烧修为"代价高）
```

#### 步骤 4 · 综合评价

| 维度 | 5 栏全开效果 |
|------|------------|
| 吸收效率 | **225%**（基础 90% × 相生加成 2.5） |
| 池上限 | **250%**（5 栏容纳量 + 相生加成） |
| 大周天效率 | **250%** |
| 大周天损耗 | **0%**（完美转化） |
| 战斗储备 | 70%（战斗主导） |
| 应急逆运 | 3%（可用，但代价高） |

**关键观察**：
- 3 对相生让"大小周天效率"×2.5（+150%）
- 5 栏降低损耗累加 120% → **完美转化**（零损耗）
- 池内 70% 战斗调用 → 战斗灵气充裕
- 唯一弱项：栏 5 逆运秘法不参与相生（栏 4→5 金不生火），无法通过相生加成提升逆运 %
