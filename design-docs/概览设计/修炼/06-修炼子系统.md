## 一、定位

修炼子系统是**角色系统**的子模块，与「角色属性子系统」「装备子系统」平级。

**与其他子系统的关系：**
- 角色属性子系统决定角色的基础成长（境界/五行/灵根）
- 修炼子系统在角色属性基础上，管理**5 个功法槽位** + **大小周天运转** + **7 灵根池（吸收公式 + 上限公式）** + **池内部分流** + **灵气/修为流转**
- 装备子系统提供额外属性加成，与修炼子系统并列加成于最终面板

## 二、核心架构 · 5 槽 × 5 类参数 矩阵

### 2.1 5 个功法槽位（保留五行方位）

| 方位 | 星宿 | 五行 | 状态 |
|------|------|------|------|
| **东** | 角亢 | 木 | 预留 |
| **南** | 井鬼 | 火 | 预留 |
| **中** | 紫薇 | 土 | **唯一生效 · 周天运转中枢** |
| **西** | 奎娄 | 金 | 预留 |
| **北** | 斗牛 | 水 | 预留 |

### 2.2 每槽对 5 类参数都有贡献（v2.0b 核心）

每部功法装备到槽位后，**同时**对以下 5 类参数有贡献：

```
5 槽位 →  各槽功法 →  5 类参数

  [角亢·东]  功法 A → 吸收 A₁% + 容纳量 B₁% + 大周天 Y₁% + 降低损耗 Z₁% + 分流 (r₁, c₁)
  [井鬼·南]  功法 B → 吸收 A₂% + 容纳量 B₂% + 大周天 Y₂% + 降低损耗 Z₂% + 分流 (r₂, c₂)
  [紫薇·中]  功法 C → 吸收 A₃% + 容纳量 B₃% + 大周天 Y₃% + 降低损耗 Z₃% + 分流 (r₃, c₃)   ← 当前唯一生效
  [奎娄·西]  功法 D → 吸收 A₄% + 容纳量 B₄% + 大周天 Y₄% + 降低损耗 Z₄% + 分流 (r₄, c₄)
  [斗牛·北]  功法 E → 吸收 A₅% + 容纳量 B₅% + 大周天 Y₅% + 降低损耗 Z₅% + 分流 (r₅, c₅)

5 槽综合（v2.0b 锁定 · 求和 + 钳制 0%-200%）：
  小周天吸收比例综合    = clamp(Σ A₁..₅, 0%, 200%)
  小周天容纳量综合      = clamp(Σ B₁..₅, 0%, 200%)
  大周天效率综合        = clamp(Σ Y₁..₅, 0%, 200%)
  大周天降低损耗综合    = clamp(Σ Z₁..₅, 0%, 200%)
  分流比例（修为）      = avg(r₁..₅)   ← 平均（保持 r + c = 100%）
  分流比例（战斗）      = avg(c₁..₅)   = 1 - 修为比例
```

**关键含义**：
- 不是"槽位功能化"，而是"**槽位叠加**"——每个槽位都对 5 类参数有贡献
- 当前 1 槽生效 = 1 套参数；未来 5 槽全开 = 5 套参数叠加
- **每个功法都必须有 5 类参数 + 3 个元字段**（名称/五行/属性加成）

## 四、功法字段（v2.0b 概念化 · 9 个必选字段）

> v2.0 删除 v1.0 的 `interface CultivationBase` 等 TypeScript 伪代码，改为**概念字段**。
> v2.0b 拆"小周天"为 2 个独立参数：**吸收比例** + **容纳量**。

每部功法有 **9 个必选字段**（W 拍板：每个功法都必须有）：

| # | 概念字段 | 含义 |
|---|---------|------|
| 1 | **名称** | 功法名字 |
| 2 | **所属五行** | 火 / 水 / 木 / 金 / 土（影响跟角色灵根的亲和度） |
| 3 | **小周天吸收比例 %** | 该功法对**小周天吸收**（浓度 × 灵根 × 功法的吸收速率）的贡献 |
| 4 | **小周天容纳量 %** | 该功法对**灵根池上限**（灵根本身上限 × 容纳量）的加成贡献 |
| 5 | **大周天效率 %** | 该功法对**大周天**（转化速度）的效率贡献 |
| 6 | **大周天降低损耗 %** | 该功法对**大周天正向损耗**的降低贡献（默认 100%，由功法降低） |
| 7 | **分流比例** | 该功法对**7 灵根池内部分流**的贡献：修为转化用 % / 战斗调用用 %（r + c = 100%） |
| 8 | **逆运 %** | 该功法对**大周天反向**的启用：默认 0%（无法反向），> 0 启用 + 转化率（修为 → 战斗灵气） |
| 9 | **属性加成** | 永久属性加成（如 atk+10, def+5） |

> **v2.0 简化说明**：v1.0 的"基础比例/基础固定值/Bonus比例/Bonus固定值/固定开销-灵根种类/固定开销-数值/反噬效果"等字段**全部删除**。

## 五、大小周天运转（v2.0b 核心）

### 5.1 小周天（吸收端 · 持续自动 · v2.0b 公式化）

| 项 | 设计 |
|-----|------|
| **输入** | 外界灵气（奇遇/时间流逝/修炼事件） |
| **吸收公式（v2.0b 新增）** | **吸纳量 = 浓度 × 灵根比例 × clamp(Σ 5 槽小周天吸收比例%, 0%, 200%) × 乾/坤加成** |
| **流程** | 按 7 灵根比例分配（沿用灵气 v2.0 规则） |
| **输出** | 7 灵根灵气池（**通用池**） |
| **池上限公式（v2.0b 新增）** | **灵根池上限 = 灵根本身上限 × clamp(Σ 5 槽小周天容纳量%, 0%, 200%)** |
| **触发** | **自动**（持续运转） |
| **当前** | 紫薇位唯一生效 |

**5 槽综合方式（v2.0b 锁定 · W 拍板 a 路线）**：
- 吸收比例综合 = Σ 5 槽 %，**clamp 0%-200%**
- 容纳量综合 = Σ 5 槽 %，**clamp 0%-200%**

**举例**（紫薇位 + 假设 4 槽预留全开）：
- 默认无功法：吸纳量 = 浓度 × 灵根比例 × 0% = 0；池上限 = 灵根本身上限 × 0% = 0（无法储存！）
- 紫薇位单槽（吸收 30% / 容纳 25%）：吸纳量 = 浓度 × 灵根 × 30%；池上限 = 灵根本身上限 × 25%
- 5 槽全开（吸收各 20% = 总 100%）：吸纳量 = 浓度 × 灵根 × 100%；池上限 = 灵根本身上限 × 100%

**关键设计**：
- **没有功法 = 0 吸收 + 0 容量**（玩家必须装功法才能修炼）
- 5 槽全开可达 100% 吸收 + 100% 容量（满状态）
- 钳制 200% 防止数值爆炸（未来可调）

### 5.2 大周天（转化端 · 主动触发）

| 项 | 设计 |
|-----|------|
| **输入** | 7 灵根灵气池中**修为转化用部分**（由分流比例决定） |
| **流程** | 灵气（修为用部分） → 修为 |
| **效率** | = Σ(5 槽位大周天 % 贡献)，clamp 0%-200% |
| **损耗** | **默认 100%；实际损耗 = clamp(100% - Σ(5 槽"大周天降低损耗 %"), 0%, 100%)** |
| **触发** | **主动**（玩家/AI 触发「运转大周天」动作） |
| **当前** | 紫薇位唯一生效 |

### 5.3 大周天反向（应急 · 主动触发）

| 项 | 设计 |
|-----|------|
| **输入** | 修为（碎境释放） |
| **输出** | 7 灵根灵气池中**战斗调用用部分（储备灵气）** |
| **默认状态** | **无法进行**（无"逆运"参数时 0% 转化） |
| **启用** | 装备带"逆运 %"参数的功法后，按"逆运 %"比例转化 |
| **逆运 % 语义** | **极低比例**（如 3%：100 修为 → 3 战斗灵气） |
| **触发** | 战斗应急（手动触发） |
| **当前** | 紫薇位无"逆运"参数 → 反向无法进行 |

**哲学**：反向 = "**燃烧修为以求活命**"，代价高（极低转化率）+ 平时无法进行。

### 5.4 7 灵根池内部分流（v2.0a 核心 · 沿用）

> 7 灵根池不是单一用途的灵气池，而是**通用池**——吸纳的灵气**内部分流**为两部分：
> - **修为转化用**（大周天正向消耗）
> - **战斗调用用 / 储备灵气**（神通消耗）
> - **分流比例 = 5 槽综合的功法"分流比例"参数的平均**

### 5.5 大小周天流转图（v2.0b 更新 · 加"浓度"输入）

```
┌─────────────────────────────────────────────────────────────┐
│                  小 周 天（自动）                            │
│                                                               │
│   外界灵气（奇遇/时间/修炼）                                  │
│        ↓                                                      │
│   **浓度**（地图/事件灵气浓度 · W 拍板）                     │
│        ↓                                                      │
│   **吸收公式**：                                              │
│     吸纳量 = 浓度 × 灵根比例 × clamp(Σ 5 槽吸收比例%, 0%, 200%)│
│            × 乾/坤加成                                       │
│        ↓                                                      │
│   按 7 灵根比例分配（灵气 v2.0）                             │
│        ↓                                                      │
│   7 灵根灵气池（通用池）                                     │
│        ↓ **池上限公式**：灵根本身上限 × clamp(Σ 5 槽容纳量%, 0%, 200%)│
│        ↓ 池内部分流（按 5 槽综合"分流比例"）                 │
│   ┌──────────────────┬──────────────────┐                    │
│   │ 修为转化用        │ 战斗调用用        │                    │
│   │ （待大周天转化）  │（储备灵气）      │                    │
│   └──────────────────┴──────────────────┘                    │
└─────────────────────────────────────────────────────────────┘
                    ↓ 主动触发（修为转化用 → 修为）
┌─────────────────────────────────────────────────────────────┐
│                  大 周 天（主动）                            │
│                                                               │
│   修为转化用部分（输入）                                     │
│        ↓  灵气 → 修为（默认 100% 损耗，                      │
│        ↓  由"大周天降低损耗 %"功法降低）                     │
│   修为（输出）                                                │
└─────────────────────────────────────────────────────────────┘
                    ↓ 战斗应急（带"逆运"功法时）
┌─────────────────────────────────────────────────────────────┐
│           大周天反向（主动 · 应急）                           │
│                                                               │
│   修为（输入）→ 碎境释放 →                                   │
│   按"逆运 %"比例注入战斗调用用（储备灵气）                   │
│   默认 0%（无逆运功法时无法进行）                             │
└─────────────────────────────────────────────────────────────┘
                    ↓
            修为 → 境界提升（02 号）
            战斗调用用（储备灵气）→ 神通消耗（14 号 §7）
```
