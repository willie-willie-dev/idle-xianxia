## 一、定位

修炼子系统是**角色系统**的子模块，与「角色属性子系统」「装备子系统」平级。

**与其他子系统的关系：**
- 角色属性子系统决定角色的基础成长（境界/五行/灵根）
- 修炼子系统在角色属性基础上，管理**5 个功法槽位** + **大小周天运转** + **7 灵根池内部分流** + **灵气/修为流转**
- 装备子系统提供额外属性加成，与修炼子系统并列加成于最终面板

## 二、核心架构 · 5 槽 × 2 周天 + 池内部分流 矩阵

### 2.1 5 个功法槽位（保留五行方位）

| 方位 | 星宿 | 五行 | 状态 |
|------|------|------|------|
| **东** | 角亢 | 木 | 预留 |
| **南** | 井鬼 | 火 | 预留 |
| **中** | 紫薇 | 土 | **唯一生效 · 周天运转中枢** |
| **西** | 奎娄 | 金 | 预留 |
| **北** | 斗牛 | 水 | 预留 |

### 2.2 每槽对小/大周天 + 分流都有贡献（v2.0a 核心）

每部功法装备到槽位后，**同时**对以下 4 件事有贡献：

```
5 槽位 →  各槽功法 →  4 类贡献参数

  [角亢·东]  功法 A → 小周天 X₁%  + 大周天 Y₁%  + 大周天降低损耗 Z₁%  + 分流 (r₁, c₁)
  [井鬼·南]  功法 B → 小周天 X₂%  + 大周天 Y₂%  + 大周天降低损耗 Z₂%  + 分流 (r₂, c₂)
  [紫薇·中]  功法 C → 小周天 X₃%  + 大周天 Y₃%  + 大周天降低损耗 Z₃%  + 分流 (r₃, c₃)   ← 当前唯一生效
  [奎娄·西]  功法 D → 小周天 X₄%  + 大周天 Y₄%  + 大周天降低损耗 Z₄%  + 分流 (r₄, c₄)
  [斗牛·北]  功法 E → 小周天 X₅%  + 大周天 Y₅%  + 大周天降低损耗 Z₅%  + 分流 (r₅, c₅)

小周天效率        = X₁ + X₂ + X₃ + X₄ + X₅
大周天效率        = Y₁ + Y₂ + Y₃ + Y₄ + Y₅
大周天降低损耗总%  = Z₁ + Z₂ + Z₃ + Z₄ + Z₅
分流比例（修为）  = avg(r₁, r₂, r₃, r₄, r₅)   ← 5 槽平均
分流比例（战斗）  = avg(c₁, c₂, c₃, c₄, c₅)
```

**关键含义**：
- 不是"槽位功能化"，而是"**槽位叠加**"——每个槽位都对 4 类参数有贡献
- 当前 1 槽生效 = 1 套参数；未来 5 槽全开 = 5 套参数叠加
- **每个功法都必须有 4 类参数**（包括分流比例）—— W 拍板

## 四、功法字段（v2.0 概念化 · 8 个必选字段）

> v2.0 删除 v1.0 的 `interface CultivationBase` 等 TypeScript 伪代码，改为**概念字段**。
> v2.0a 每个功法**必须有 8 个字段**（W 拍板：每个功法都必须有"分流比例"参数）。

| # | 概念字段 | 含义 |
|---|---------|------|
| 1 | **名称** | 功法名字 |
| 2 | **所属五行** | 火 / 水 / 木 / 金 / 土（影响跟角色灵根的亲和度） |
| 3 | **小周天效率 %** | 该功法对**小周天**（吸收+储存）的效率贡献 |
| 4 | **大周天效率 %** | 该功法对**大周天**（转化速度）的效率贡献 |
| 5 | **大周天降低损耗 %** | 该功法对**大周天正向损耗**的降低贡献（默认 100%，由功法降低） |
| 6 | **分流比例** | 该功法对**7 灵根池内部分流**的贡献：修为转化用 % / 战斗调用用 %（r + c = 100%） |
| 7 | **逆运 %** | 该功法对**大周天反向**的启用：默认 0%（无法反向），> 0 启用 + 转化率（修为 → 战斗灵气） |
| 8 | **属性加成** | 永久属性加成（如 atk+10, def+5） |

> **v2.0 简化说明**：v1.0 的"基础比例/基础固定值/Bonus比例/Bonus固定值/固定开销-灵根种类/固定开销-数值/反噬效果"等字段**全部删除**——先专注 5 槽 × 2 周天 + 池内部分流 + 逆运的核心矩阵概念。

## 五、大小周天运转（v2.0 核心）

### 5.1 小周天（吸收端 · 持续自动）

| 项 | 设计 |
|-----|------|
| **输入** | 外界灵气（奇遇/时间流逝/修炼事件） |
| **流程** | 按 7 灵根比例分配（沿用灵气 v2.0 规则） |
| **输出** | 7 灵根灵气池（**通用池**） |
| **效率** | = Σ(5 槽位小周天 % 贡献) |
| **触发** | **自动**（持续运转） |
| **当前** | 紫薇位唯一生效（1 槽贡献） |

### 5.2 大周天（转化端 · 主动触发）

| 项 | 设计 |
|-----|------|
| **输入** | 7 灵根灵气池中**修为转化用部分**（由分流比例决定） |
| **流程** | 灵气（修为用部分） → 修为 |
| **效率** | = Σ(5 槽位大周天 % 贡献) |
| **损耗（v2.0a 改）** | **默认 100%；实际损耗 = clamp(100% - Σ(5 槽"大周天降低损耗 %"), 0%, 100%)** |
| **触发** | **主动**（玩家/AI 触发「运转大周天」动作） |
| **当前** | 紫薇位唯一生效 |

**举例**（紫薇位 + 假设 4 槽预留全开）：
- 默认 100% 损耗 → 1 灵气 → 0 修为（完全浪费）
- 紫薇位 "大周天降低损耗 50%" → 实际损耗 50% → 1 灵气 → 0.5 修为
- 5 槽全开，"大周天降低损耗" 累加 = 100% → 实际损耗 0% → 1 灵气 → 1 修为（完美转化）

### 5.3 大周天反向（应急 · 主动触发 · v2.0a 重写）

| 项 | 设计 |
|-----|------|
| **输入** | 修为（碎境释放） |
| **输出** | 7 灵根灵气池中**战斗调用用部分（储备灵气）** |
| **默认状态** | **无法进行**（无"逆运"参数的功法时，0% 转化） |
| **启用** | 装备带"逆运 %"参数的功法后，按"逆运 %"比例转化 |
| **逆运 % 语义** | **极低比例**（如 3%：100 修为 → 3 战斗灵气） |
| **触发** | 战斗应急（手动触发） |
| **当前** | 紫薇位无"逆运"参数 → 反向无法进行 |

**哲学**：
- 反向 = "**燃烧修为以求活命**"
- 代价高（极低转化率）+ 平时无法进行（必须有专门带"逆运"的功法）
- W 原话：「由于反向是特殊情况，约等于"燃烧修为"以求活命」

### 5.4 7 灵根池内部分流（v2.0a 核心 · 新增）

> **关键设计**：7 灵根池不是单一用途的灵气池，而是**通用池**——吸纳的灵气**内部分流**为两部分。

**分流方式**：
- 灵气吸纳到 7 灵根池后，按 **5 槽综合的分流比例** 切分：
  - **修为转化用**（标记为"待大周天转化"）
  - **战斗调用用（储备灵气）**（标记为"待神通消耗"）
- **5 槽综合的分流比例 = 5 槽各功法"分流比例"的平均**
  - 修为比例 = avg(r₁, r₂, r₃, r₄, r₅)
  - 战斗比例 = avg(c₁, c₂, c₃, c₄, c₅) = 1 - 修为比例

**举例**（5 槽全开假设）：
- 功法 A：修为 30% / 战斗 70%
- 功法 B：修为 50% / 战斗 50%
- 功法 C：修为 40% / 战斗 60%
- 功法 D：修为 60% / 战斗 40%
- 功法 E：修为 20% / 战斗 80%
- 总修为 = avg(30%, 50%, 40%, 60%, 20%) = 40%
- 总战斗 = avg(70%, 50%, 60%, 40%, 80%) = 60%

→ 1 单位灵气吸纳 → 0.4 修为用 + 0.6 战斗用

**当前**：紫薇位 1 槽生效 → 紫薇位的分流比例 = 全部（无平均）

**W 拍板**：**每个功法都必须有"分流比例"参数**（r + c = 100%）。
