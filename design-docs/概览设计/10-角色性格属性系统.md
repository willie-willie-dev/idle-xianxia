## 一、模块定位

性格属性系统是**角色系统中"人格偏好 + 神识能力 + 肉身能力"**的总和，按五行（**火/水/木/金/土**）一一对应组织。

| 维度 | 类别 | 回答的问题 | 是否影响事件结算 |
|------|------|-----------|-----------------|
| **性格**（人格偏好维） | 偏好 | 角色「倾向于怎样选」 | ✅ 影响事件选项倾向 |
| **灵魂**（神识能力维） | 能力 | 角色「神识层面能做到什么程度」 | ⏳ 待战�斗系统联调 |
| **肉体**（身法/体质维） | 能力 | 角色「肉身层面能做到什么程度」 | ⏳ 待战斗系统联调 |

> **重要边界**：三者同源五行、意象可呼应，但**数据、字段、结算必须强制分离**——尤其是同名（如「刚毅」在金·灵魂与金·性格阳之间）绝不共用同一字段。

## 二、整体结构：3 层性格 + 平行 2 维能力

```
角色性格属性系统
├── 性格（人格偏好维：3 层）
│   ├── 锚定词（中性基底）   5 词
│   ├── 阳面（积极表现）     5 词
```

五行共 25 词一一对应：每个五行都有 1 个锚定 + 1 个阳 + 1 个阴 + 1 个灵魂 + 1 个肉体。

## 四、性格（人格偏好维）：3 层结构

### 4.1 锚定词（中性基底）

每个五行方向都有一个**中性锚定词**——是该五行方向的核心气质基底，**不属于积极也不属于消极**。

| 锚定词 | 含义（中性） |
|--------|-------------|
| 激进 | 主动推进、向外扩张 |
| 交融 | 渗入混合、连接融合 |
| 繁茂 | 生长延续、滋养生发 |
| 坚刚 | 坚硬不可夺、稳固如金 |
| 固守 | 守住不散、包裹保全 |

> 锚定词是**整个五行性格结构的底色**——阳面、阴面都是同一个锚定的两种偏走法。

### 4.2 阳面（积极表现）

阳面是锚定词的**正向走法**——同一个"激进"底色，可以是「热血」也可以是「贪婪」。前者积极，后者消极。

| 五行 | 阳面 | 含义 |
|------|------|------|
| 火 | 热血 | 积极介入、主动担当 |
| 水 | 包容 | 忠贞接纳、广纳百川 |
| 木 | 传承 | 延续珍视之物、薪火相传 |
| 金 | 刚毅 | 坚守道义、不屈不挠 |
| 土 | 厚德 | 承载滋养、默默付出 |

### 4.3 阴面（消极表现）

阴面是锚定词的**负向走法**——同源同底，但放错了方向。

| 五行 | 阴面 | 含义 |
|------|------|------|
| 火 | 贪婪 | 掠夺资源、过度索取 |
| 水 | 纵欲 | 无度追求、沉溺失度 |
| 木 | 掌控 | 控制他人意志、强加于人 |
| 金 | 冷酷 | 为达目的不择手段 |
| 土 | 吝啬 | 过度守护不放、宁死不给出 |

### 4.4 行为模式派生

> **行为模式 = 锚定 × 阳 + 锚定 × 阴 的合力**。
> 一个善良的人也可能贪，只是靠性格压制住欲望；行为模式由这三层共同决定。

本节是后续扩展点（待事件映射规则细化后展开）。

## 七、数据结构

```typescript
/** 五行性格（3 层：锚定 / 阳 / 阴） */
interface FiveElements {
  fire:  { yang: number; yin: number };
  water: { yang: number; yin: number };
  wood:  { yang: number; yin: number };
  metal: { yang: number; yin: number };
  earth: { yang: number; yin: number };
}

/** 灵魂五行能力（与 FiveElements 性格无关） */
interface SoulAttrs {
  fire:  number;   // 果断
  water: number;   // 变通
  earth: number;   // 隐忍
  wood:  number;   // 执着
  metal: number;   // 刚毅
}

/** 肉体五行能力（与 FiveElements 性格无关） */
interface BodyAttrs {
  fire:  number;   // 迅捷
  water: number;   // 灵巧
  earth: number;   // 厚重
  wood:  number;   // 生机
  metal: number;   // 坚韧
  zangfu?: ZangFu; // 详见 02-角色属性系统.md
}

/** 性格偏移接口（事件模板调用） */
interface TemperamentShift {
  dimension: FiveElementsDimension;  // 例：'fire.yang'
  value: number;                      // 偏移量，通常为 ±1
}

export type FiveElementsDimension =
  | 'fire.yang' | 'fire.yin'
  | 'water.yang' | 'water.yin'
  | 'wood.yang' | 'wood.yin'
  | 'metal.yang' | 'metal.yin'
  | 'earth.yang' | 'earth.yin';
```

## 八、字段强制分离规则

> ⚠️ **同名字段必须区分领域**。

| 词 | 出现位置 | UI 标注示例 |
|----|----------|------------|
| 刚毅 | 金·灵魂（能力） | 灵魂·金·刚毅 |
| 刚毅 | 金·性格阳（偏好） | 性格·金·阳·刚毅 |

**规则**：
- 数据层字段必须独立（`SoulAttrs.metal` ≠ `FiveElements.metal.yang`）
- UI 层必须标注领域（灵魂 / 性格 / 肉体的前缀）
- 文档、事件模板、结算逻辑中**禁止**交叉引用

## 九、与修为灵根的关系

| 系统 | 字段 | 关系 |
|------|------|------|
| 五行灵根（修为） | `element` | 性格初始化的锚点 |
| 五行性格（偏好） | `fiveElements` | 阳阴按 element 锚定生成初值 |
| 灵魂五行（能力） | `soul` | 暂不与 element 联动 |
| 肉体五行（能力） | `body` | 暂不与 element 联动 |

> 修为灵根作为五行性格的**初始锚点**，角色创建时由角色系统根据 `element` 生成初始值；后续由事件选项结算持续修正，修正结果不受修为灵根约束。

## 十、运行机制

### 性格偏移（阳/阴）

每次事件选项结算时：

1. 根据选项的 `temperamentShift` 字段应用偏移
2. 将偏移量叠加到对应的五行性格维度上
3. 数值下限 0，上限不封顶（超过 100 继续增长）
4. 无衰减机制（性格一旦形成不回落）

### 灵魂/肉体

> ⏳ 当前不进入核心事件运算。预留接口，待战斗系统设计完成后联调。
