## 二、核心玩法框架

> 本章为游戏结构的最顶层设计索引。已于 **2026-08-04** 重新独立为 [`00-01-核心玩法.md`](./00-01-核心玩法.md)。

### 2.1 核心循环

**从角色界面触发，进入连续事件选择，获得回馈。** 闭合反馈循环，全系统服务于此。

→ 详见 [`00-01-核心玩法.md` §二](./00-01-核心玩法.md)

### 2.2 子系统衍生关系

核心循环向外衍生：事件响应能力、战斗系统、回馈收益系统。

→ 详见 [`00-01-核心玩法.md` §2.1](./00-01-核心玩法.md)

### 2.3 三条回馈循环

角色成长循环（核心）、战斗成长循环、事件成长循环，三者并行服务于角色成长。

→ 详见 [`00-01-核心玩法.md` §2.2](./00-01-核心玩法.md)

### 2.4 核心界面入口

主入口为角色界面；历练方向（吸纳 / 奇遇 / 战斗 / 危机）进入对应循环后回流。

→ 详见 [`00-01-核心玩法.md` §2.3](./00-01-核心玩法.md)

## 三、系统职责

### 3.1 角色（01）

| 文档 | 职责 |
|------|------|
| **01-01 角色属性** | 寿元、境界、灵根；性格已迁出 |
| **01-02 性格属性** | 性格阴阳、灵魂、肉体 |
| **01-03 战意** | 战斗意愿决策；不选具体神通 |
| **01-04 装备** | 槽位、品质、强化、套装 |
| **01-05 修炼** | 五槽功法、小周天、大周天、修为 |
| **01-06 灵气吸收** | 七灵根吸收规则 |
| **01-07 精神状态** | 临时心态；战斗与修炼影响待定 |
| **01-08 角色属性总览** | 角色侧文档的全景地图，不是新规则 |

### 3.2 事件（02）

| 文档 | 职责 |
|------|------|
| **02-01 事件** | 历练触发与结算 |
| **02-02 奇遇生成器** | 机缘类事件生成 |
| **02-03 时间** | 游戏内时间、事件耗时、挂机 tick |

### 3.3 战斗（03）

**03-01** 是执行层：HP、肉体五行抗性、神通、伤害结算。周天与修为的定义在 **01-05**，03-01 只引用。

### 3.4 界面与项目

界面方案在 **04**。协作约束在 **05-01**。旧实现对照文档在各类的 `归档/`。
